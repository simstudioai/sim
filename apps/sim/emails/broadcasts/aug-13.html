Realtime

Realtime collaboration in tables and files

Tables and files are now realtime. You and your teammates can be in the same table at the same time, and so can your agents. Someone edits a row while an agent fills in a hundred more next to them. A file updates while Sim is still writing it. Everyone sees all of it as it happens, with no refreshing and no stale copies.

This is the part I'm most excited about. Working with an agent should feel like working with someone on your team, and now it finally does.
Workflows

Workflow UI redesign

We last updated the workflow blocks almost a year ago. It was time for a change, so we rebuilt them into something cleaner and more powerful. It's the same canvas you already know, redesigned from the block up. We hope you enjoy it.

As always, please tell us what you think. We read every reply, and a lot of what's in this release came from people writing in.
