[Oracle Database](/integrations/oracle-database) joins Sim's integrations. Query records, insert or update rows, and inspect tables and columns from a workflow. Save a connection in Integrations and reuse it across your agents, with support for encrypted connections.

Requires Oracle Database 12.1 or later, reachable from your Sim runtime; self-hosted installations need Node.js 24. [Connect Oracle Database](https://docs.sim.ai/integrations/oracledb).

### More integrations in v0.9.17

- **[Checkr](/integrations/checkr):** Create candidates, send background-check invitations, read reports, and start workflows from report or invitation events using your Checkr API key.
- **[Shopify](/integrations/shopify):** Create or update product variants in bulk, look up fulfillment orders, and update shipment tracking; expiring connections refresh automatically.
- **[Ramp](/integrations/ramp) and [Vanta](/integrations/vanta):** Save a client ID and secret once and reuse the connection across blocks. Existing workflows with inline Vanta credentials must [create and select a saved credential](https://docs.sim.ai/integrations/vanta) before running again.

### Chat fixes in v0.9.23

- Interrupted Chat runs can recover after a server restart without waiting for you to reopen the chat.
- Resizing a Chat panel keeps your chosen width even if you switch windows before releasing the pointer.
