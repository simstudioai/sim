Your agents can now query [Power BI](/integrations/power-bi) data, browse reports, and manage model refreshes. Pull revenue by region into a sales briefing or check refresh status before using the latest data.

[Connect Power BI](https://docs.sim.ai/integrations/powerbi) to get started. Queries require Read and Build permissions and your tenant's Execute Queries setting.
