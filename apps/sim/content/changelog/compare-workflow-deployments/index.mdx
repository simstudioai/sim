Sim now shows what changed between workflow versions in a single comparison. Review prompt edits, added or removed steps, and changed connections together before updating an agent’s deployment.

You can review two kinds of changes:

- **Deployment against deployment:** choose two saved versions to understand what changed between releases.
- **Draft against live:** check the work in progress against the version that currently handles incoming requests.

For example, if you revise a support agent’s instructions and add a Slack step, the comparison brings the prompt edit, new step, and connection into the same view. Use it to check a planned update or revisit the differences between earlier deployments.

Open **Compare** in deployment history to choose versions, or **View changes** on your draft to review it against the live workflow. [Learn how workflow deployments work](https://docs.sim.ai/workflows/deployment), including version history and promoting an earlier version back to live.
