Move a knowledge base between Sim workspaces or deployments without rebuilding it document by document. Export a `.simkb.zip` archive, then import it through the Sim CLI or API to create a new base with its documents, tags, and settings.

When the archive includes a search index compatible with the destination's embedding model and dimensions, Sim reuses it without embedding charges. Otherwise, Sim processes the documents again, with normal usage charges.

The original base stays unchanged. Exports include only active, included documents readable by the whole workspace. Imported connector content is a snapshot; live connections and access permissions do not transfer. Your permissions must allow export in the source and knowledge-base creation and uploads in the destination. [Export and import guide](https://docs.sim.ai/knowledgebase/export-import).

### Also in v0.9.32

- **[Amazon EC2](/integrations/amazon-ec2):** Agents and workflows can inspect and control instances, create disk snapshots, and manage resource tags using an AWS access key with the required permissions. [EC2 setup](https://docs.sim.ai/integrations/ec2).
