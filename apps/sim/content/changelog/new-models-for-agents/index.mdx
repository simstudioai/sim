[GPT-6.1 Sol](/models/openai/gpt-6-1-sol), [Claude Haiku 5.5](/models/anthropic/claude-haiku-5-5), and [Grok 4.7](/models/xai/grok-4-7) are now available in Sim’s Agent block. Switch models while keeping your prompts, connected integrations, and workflow structure. [Configure an Agent block](https://docs.sim.ai/workflows/blocks/agent).

### Also in v0.9.15

- **Agent defaults:** Organization admins can choose a default model in a permission group. Newly created Agent blocks use that allowed default; explicitly selected models stay as they are. Available with [permission groups](https://docs.sim.ai/platform/enterprise/access-control) on Sim Cloud Enterprise and configured self-hosted deployments.
