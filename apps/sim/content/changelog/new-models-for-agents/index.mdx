Open an Agent block and choose [GPT-6.1 Sol](/models/openai/gpt-6-1-sol), [Claude Haiku 5.5](/models/anthropic/claude-haiku-5-5), or [Grok 4.7](/models/xai/grok-4-7) from the model picker. Keep your prompts and connected integrations, then review the model's settings before running it.

For example, try a different model on a support-ticket summary and compare its response using the same sample input. The screenshot shows configuration only; no model response was generated.

Included in [v0.9.15](https://github.com/simstudioai/sim/releases/tag/v0.9.15). Model access depends on your provider account and credentials. Follow the [Agent block guide](https://docs.sim.ai/workflows/blocks/agent) for setup.
