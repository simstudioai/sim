Find the work waiting on a person without opening every workflow. In v0.9.54, the [Sim CLI](https://docs.sim.ai/cli/workflows) and API can list paused runs across a workspace, including the review or input each run needs. Details follow your access permissions.

You can also [list workspace schedules](https://docs.sim.ai/cli/schedules) to see their timing and health in one place. Change a schedule's timing in its workflow and redeploy it.

### More control in v0.9.53

Run an earlier deployed version through the API without making it the active version. This lets you check a previous version while the current deployment keeps serving new work. Pinning a version requires Write access. [Run a deployed version](https://docs.sim.ai/workflows/deployment/api).

Inspect a deployed trigger's health, disable it, or enable it again through the CLI or API. Disabling lasts until the next deployment or version activation and does not cancel work already running.

### Also for data workflows

- **v0.9.53 — PDF images:** Mistral Parser V3 can return images from an uploaded or referenced PDF as files for later steps, and extract tables as Markdown or HTML. [Parser guide](https://docs.sim.ai/integrations/mistral_parse).
- **v0.9.47 — CSV codes:** New CSV columns keep leading-zero values such as ZIP codes and SKUs as text instead of dropping their zeros.

For new automation, use the current Sim CLI or HTTP API. The legacy `simstudio` CLI and Python and TypeScript SDKs were retired in v0.9.53.
