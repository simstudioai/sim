### Improvements

- Sim scans code placeholders and workflow references more efficiently as code blocks grow. See the [Function block guide](https://docs.sim.ai/workflows/blocks/function) for working with code in your agents.
- Files retain their known origins when exported as binary files or extracted from archives, so [secret tracking](/blog/secret-provenance) can follow those transformations.

### Fixes

- Background workflow confirmations now preserve the identity of the workflow run they belong to.

Explore [Files in Sim](/files) and the guide to [using files in workflows](https://docs.sim.ai/files/using-in-workflows).
