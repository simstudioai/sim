[Nebius Token Factory](/models/nebius) is now available in Sim’s Agent block. Choose from open models including DeepSeek, Kimi, and Qwen, and run them through your Nebius account alongside the other model providers you use in Sim.

Try a Nebius model in an agent that summarizes support tickets, extracts details from incoming requests, or drafts a response using connected tools. You can keep the block’s existing prompts and connections while changing the model, then run representative inputs to see how it handles your task. Check the selected model’s supported features when using image inputs or structured outputs.

To get started, bring your own Nebius API key and search for **nebius** in the Agent block’s model picker. On Sim Cloud, a workspace admin adds the key under **Workspace settings → BYOK → Nebius**. Self-hosted teams provide it in the block’s **API Key** field. [Set up Nebius in an Agent block](https://docs.sim.ai/workflows/blocks/agent).
