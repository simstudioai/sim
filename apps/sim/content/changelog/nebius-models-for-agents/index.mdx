[Nebius Token Factory](/models/nebius) is now available in Sim’s Agent block. Choose from open models including DeepSeek, Kimi, and Qwen, and use them with your existing prompts and connected tools. Tool use, image inputs, and structured outputs depend on the selected model.

Bring your own Nebius API key. On Sim Cloud, a workspace admin adds it under **Workspace settings → BYOK → Nebius**; self-hosted users provide it in the Agent block’s **API Key** field. [Set up Nebius in an Agent block](https://docs.sim.ai/workflows/blocks/agent).
