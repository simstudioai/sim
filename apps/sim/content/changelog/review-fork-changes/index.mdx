Review source workflow changes before syncing them into a workspace fork. **Last Sync → Now** compares the source at the last successful sync with its current deployment, showing prompt, setting, and workflow changes. Each fork and sync direction keeps its own baseline.

Choose **Compare** from a deployed workflow’s menu in the fork’s mapping settings. A successful sync must establish the baseline first.

Available with Forks enabled on Sim Cloud Enterprise or self-hosted deployments. Managing a sync requires admin access to both workspaces. [Learn more about workspace forks](https://docs.sim.ai/platform/enterprise/forks).
