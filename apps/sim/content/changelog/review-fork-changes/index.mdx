Open **Workspace forks**, choose **Edit mappings** for the parent workspace, and select **Push** or **Pull**. Then choose **Compare** from a deployed workflow's menu. **Last Sync → Now** shows changes to the source workflow since the version last brought across.

Review prompt edits, configuration changes, and added or removed steps before syncing. Each fork and sync direction keeps its own history, so a comparison in one child workspace does not reuse another child's baseline.

The baseline advances only after the destination deployment becomes active. If a workflow has never been synced, or its earlier snapshot is unavailable, Sim explains why there is no comparison instead of guessing.

Included in **v0.9.12**. Workspace forks require workspace admin access and are available on Sim Cloud Enterprise when enabled for the organization, or on self-hosted deployments with Forks enabled. The [workspace forks guide](https://docs.sim.ai/platform/enterprise/forks) covers setup and sync behavior.
