Sim now lets you review changes to a source workflow before syncing them into a workspace fork. The **Last Sync → Now** comparison shows what changed in the source since it was last successfully synced, including edits to prompts, settings, and workflow steps.

If you maintain a shared agent across several workspaces, use the comparison to understand an update before bringing it into a fork. For example, check a revised renewal-reminder interval and new settings together before syncing. Each fork and sync direction keeps its own baseline, so the review reflects that particular relationship.

Open the fork’s mapping settings, choose the sync direction, and select **Compare** from a deployed workflow’s menu. Comparison becomes available after a successful sync establishes a baseline; the source snapshots must still be available.

Available with Forks enabled on Sim Cloud Enterprise or self-hosted deployments. Managing a sync requires admin access to both workspaces. [Learn more about workspace forks](https://docs.sim.ai/platform/enterprise/forks).
