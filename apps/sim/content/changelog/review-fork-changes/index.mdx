Review changes to a source workflow before syncing them into a workspace fork. Compare prompts, settings, and steps against the last successful sync, with a separate history for each fork and sync direction.

Available to workspace admins with Forks enabled on Sim Cloud Enterprise or self-hosted deployments. [Learn more about workspace forks](https://docs.sim.ai/platform/enterprise/forks).
