Read workspace access and manage reviewed fork, push, and pull operations.

`sim workspaces` is also spelled `sim workspace`.

These commands accept the [global options](/cli/commands#global-options).

## Workspace access

### List workspaces

```bash
sim workspaces list [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--sort-by <value>` | No | Field used to sort the result. Do not rely on case-insensitive ordering when sorting by `name`. Defaults to "createdAt". Accepted values: `name`, `createdAt`, `updatedAt`. |
| `--sort-order <value>` | No | Sort direction. Defaults to "desc". Accepted values: `asc`, `desc`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `0`. |

</CommandTable>

API request and response schemas: [listWorkspaces](/api-reference/workspaces/listWorkspaces).

### Create workspace invitations

OAuth login or personal API key required.

```bash
sim workspaces invitations create [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--emails <value...>` | Yes | Email addresses to invite. Each address is processed separately; inspect failed for unsuccessful recipients. (space-separated, or @path / @- with one value per line; @@value for a literal leading @). |
| `--permission <value>` | No | Workspace permission to grant. Existing workspace access is preserved. Defaults to "read". Accepted values: `admin`, `write`, `read`. |
| `--membership <value>` | No | Organization membership: member or admin uses a seat when billing is enabled. External grants workspace access only and requires an eligible paid account when billing is enabled. Existing members of another organization remain external. Defaults to "member". Accepted values: `member`, `admin`, `external`. |

</CommandTable>

API request and response schemas: [createWorkspaceInvitations](/api-reference/workspaces/createWorkspaceInvitations).

## Access requests

### Discover workspace access requests

OAuth login or personal API key required.

```bash
sim workspaces access-requests discover [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--search <value>` | No | Case-insensitive substring match against the access item label. |
| `--target-kind <value>` | No | Category of access to discover. Accepted values: `feature`, `integration`, `provider`, `model`, `tool`, `knowledge_connector`, `file_share_auth`, `chat_deploy_auth`, `usage_limit`. |
| `--state <value>` | No | Filter by the acting user’s current access. Requestable items can be submitted for review. Accepted values: `allowed`, `requestable`, `unavailable`. |
| `--sort-by <value>` | No | Field used to sort the result. Defaults to "label". Accepted values: `label`. |
| `--sort-order <value>` | No | Sort direction. Defaults to "asc". Accepted values: `asc`, `desc`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `100`. |
| `--cursor <value>` | No | Continue from nextCursor returned by a previous result. |

</CommandTable>

API request and response schemas: [discoverWorkspaceAccessRequests](/api-reference/access-requests/discoverWorkspaceAccessRequests).

## Push and pull

### Preview workspace push

OAuth login or personal API key required.

```bash
sim workspaces push-preview [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--other-workspace-id <value>` | Yes | Workspace on the other side of the direct fork edge. |
| `--mappings <json\|@file>` | No | Proposed mapping entries addressed by resource type and `sourceId`. Preview does not save them; apply commits them with the sync. (JSON, or @path / @- to read a file or stdin). |
| `--dependent-values <json\|@file>` | No | Destination-specific choices addressed by source workflow ID, source block ID, and field key. Omission keeps saved overrides; an explicit empty array clears them. (JSON, or @path / @- to read a file or stdin). |

| `--drop-references <json\|@file>` | No | Source-deleted references explicitly acknowledged for removal; live source references cannot be dropped. (JSON, or @path / @- to read a file or stdin). |
| `--trigger-mappings <json\|@file>` | No | Public trigger path choices from preview.triggerSlots, addressed by source workflow and block IDs. Duplicate or unavailable choices are rejected. (JSON, or @path / @- to read a file or stdin). |

</CommandTable>

API request and response schemas: [previewWorkspacePush](/api-reference/workspace-sync/previewWorkspacePush).

### Wait for workspace copy and deployment readiness [#wait-for-copy-and-deployment-readiness-exit-3-for-configuration-1-for-failure-or-4-for-timeout]

```bash
sim workspaces operations wait <operationId> [options]
```

**Arguments**

<CommandTable>

| Argument | Required | Description |
| --- | --- | --- |
| `operationId` | Yes | Operation ID returned by import, fork, push, or pull |

</CommandTable>

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--wait-timeout <seconds>` | No | Maximum total wait (default 3600; 0 waits indefinitely). |

</CommandTable>

Exit codes: 0 completed (including completion with warnings), 1 follow-up work failed, 3 destination configuration is required, 4 timed out. The mutation may already be committed; reconcile using the same operation or request ID rather than repeating it with a new ID.

API request and response schemas: [getWorkspaceOperation](/api-reference/workspace-sync/getWorkspaceOperation).
