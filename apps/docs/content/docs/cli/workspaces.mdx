`sim workspaces` is also spelled `sim workspace`.

Every command below also accepts the [global options](/cli/commands#global-options).

## Fork workspace

```bash
sim workspaces fork [options]
```

Fork Workspace (OAuth login or personal API key required)

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--name <value>` | No | Display name of the workflow or workspace. |
| `--copy <json\|@file>` | No | Explicit resource selections to copy into the new fork; omitted resource kinds are not copied. (JSON, or @path / @- to read a file or stdin). |
| `--request-id <value>` | Yes | Stable client request ID for reconciliation and identical retries. |
| `--preview-fingerprint <value>` | Yes | Fingerprint of the reviewed preview and its choices. |
| `--wait` | No | Wait for the committed operation to finish; missing configuration and failure exit nonzero. |
| `--wait-timeout <seconds>` | No | Maximum operation wait in seconds (default 3600; 0 waits indefinitely). |

</CommandTable>

## Get workspace fork mappings

```bash
sim workspaces mappings get [options]
```

Get Workspace Fork Mappings (OAuth login or personal API key required)

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--other-workspace-id <value>` | Yes | Workspace on the other side of the direct fork edge. |
| `--direction <value>` | Yes | Push means current to other; pull means other to current, independent of parent/child orientation. Accepted values: `push`, `pull`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `100`. |
| `--cursor <value>` | No | Continue from nextCursor returned by a previous result. |
| `--sort-by <value>` | No | Supported stable sort key for this collection. Accepted values: `id`. |
| `--sort-order <value>` | No | Sort direction. Accepted values: `asc`. |

</CommandTable>
