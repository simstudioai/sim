Inspect and change this machine’s anonymous usage-reporting preference.

These commands accept the [global options](/cli/commands#global-options).

## Show usage-reporting status [#show-whether-usage-reporting-is-on-and-why-not-if-it-is-off]

```bash
sim telemetry status
```

Telemetry commands always print text. DO_NOT_TRACK and SIM_TELEMETRY_DISABLED override the saved preference; a build without a reporting destination remains off. See the usage-data guide for the data collected.

## Turn usage reporting off for this machine

```bash
sim telemetry disable
```

## Enable the usage-reporting preference for this machine [#turn-usage-reporting-on-for-this-machine]

```bash
sim telemetry enable
```
