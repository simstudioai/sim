Discover providers, connect accounts, and manage credential access.

Run `sim --output json credentials providers list` to inspect the provider’s fields and authentication requirements before creating a service-account credential. OAuth connection commands return a link that a person must open to authorize the connection.

`sim credentials` is also spelled `sim credential`.

These commands accept the [global options](/cli/commands#global-options).

## Provider discovery and connections

### List credential providers

```bash
sim credentials providers list [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--search <value>` | No | Case-insensitive substring match against the credential provider name. |

</CommandTable>

API request and response schemas: [listCredentialProviders](/api-reference/credentials/listCredentialProviders).

### List credentials

```bash
sim credentials list [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--type <value>` | No | Restrict results to this credential type. Accepted values: `oauth`, `service_account`. |
| `--provider-id <value>` | No | Restrict results to credentials for this integration provider. |
| `--search <value>` | No | Case-insensitive substring match against the credential display name. |
| `--sort-by <value>` | No | Field used to sort the result. Defaults to "createdAt". Accepted values: `displayName`, `createdAt`, `updatedAt`. |
| `--sort-order <value>` | No | Sort direction. Defaults to "desc". Accepted values: `asc`, `desc`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `0`. |

</CommandTable>

API request and response schemas: [listCredentials](/api-reference/credentials/listCredentials).

### Create a service-account credential using its discovered provider schema

OAuth login or personal API key required.

```bash
sim credentials create <providerId> [options]
```

**Arguments**

<CommandTable>

| Argument | Required | Description |
| --- | --- | --- |
| `providerId` | Yes | Service-account provider to create a credential for |

</CommandTable>

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--name <displayName>` | Yes | Name shown for the credential in Sim. |
| `--credentials <json\|@file>` | Yes | Provider credentials as JSON (or @path / @- to read a file or stdin). |
| `--description <description>` | No | Optional credential description. |
| `--id <credentialId>` | No | Client-generated credential ID when provider discovery requires it. |

</CommandTable>

API request and response schemas: [createServiceAccountCredential](/api-reference/credentials/createServiceAccountCredential).

## Credential members

OAuth login or personal API key required.

```bash

```

**Arguments**

<CommandTable>

| Argument | Required | Description |
| --- | --- | --- |
| `credentialId` | Yes | Credential whose sharing grants are managed. |

</CommandTable>

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `0`. |
| `--sort-by <value>` | No | Field used to sort the result. Do not rely on case-insensitive ordering when sorting by `name`. Defaults to "email". Accepted values: `email`, `name`. |
| `--sort-order <value>` | No | Sort direction. Defaults to "asc". Accepted values: `asc`, `desc`. |

</CommandTable>
