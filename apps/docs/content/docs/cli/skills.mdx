Create reusable agent instructions and manage their editors.

`sim skills` is also spelled `sim skill`.

These commands accept the [global options](/cli/commands#global-options).

## Skill instructions

### List skills

```bash
sim skills list [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--search <value>` | No | Case-insensitive substring match against the skill name. |
| `--sort-by <value>` | No | Field used to sort the result. Do not rely on case-insensitive ordering when sorting by `name`. Defaults to "createdAt". Accepted values: `name`, `createdAt`, `updatedAt`. |
| `--sort-order <value>` | No | Sort direction. Defaults to "desc". Accepted values: `asc`, `desc`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `0`. |

</CommandTable>

API request and response schemas: [listSkills](/api-reference/skills/listSkills).

### Get skill

```bash
sim skills get <skillId>
```

**Arguments**

<CommandTable>

| Argument | Required | Description |
| --- | --- | --- |
| `skillId` | Yes | Unique skill identifier. A built-in skill is `builtin-` followed by its name, for example `builtin-research`. |

</CommandTable>

API request and response schemas: [getSkill](/api-reference/skills/getSkill).

### Create skill

OAuth login or personal API key required.

```bash
sim skills create [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--name <value>` | Yes | Kebab-case name, unique within the workspace and not reserved by a built-in skill. |
| `--description <value>` | Yes | One-line summary of when the skill applies. |
| `--content <value>` | Yes | Skill body containing the instructions given to the agent. |

</CommandTable>

API request and response schemas: [createSkill](/api-reference/skills/createSkill).

### Update skill

**Arguments**

<CommandTable>

| Argument | Required | Description |
| --- | --- | --- |
| `skillId` | Yes | Unique skill identifier. A built-in skill is `builtin-` followed by its name, for example `builtin-research`. |

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |

</CommandTable>

API request and response schemas: [updateSkill](/api-reference/skills/updateSkill).

### Revoke skill editor

OAuth login or personal API key required.

This revokes the explicit skill editor grant for the selected email.

```bash
sim skills editors delete <skillId> [options]
```

**Arguments**

<CommandTable>

| Argument | Required | Description |
| --- | --- | --- |
| `skillId` | Yes | Unique skill identifier. A built-in skill is `builtin-` followed by its name, for example `builtin-research`. |

</CommandTable>

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--email <value>` | Yes | Email address of a current workspace member. |
| `-y, --yes` | Yes | Confirm this operation. |

</CommandTable>

API request and response schemas: [revokeSkillEditor](/api-reference/skills/revokeSkillEditor).
