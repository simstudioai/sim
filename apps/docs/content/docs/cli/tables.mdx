Manage tables, rows, schemas, views, enrichment runs, imports, and exports.

`sim tables` is also spelled `sim table`.

These commands accept the [global options](/cli/commands#global-options).

## Tables

### List tables

```bash
sim tables list [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--scope <value>` | No | Which lifecycle set to list: `active` (default) for live tables, `archived` for tables a delete archived and a table restore can bring back. `folderPath` resolves against active folders only, so pairing it with `scope=archived` returns an empty page when the containing folder was archived too. Accepted values: `active`, `archived`. |
| `--folder <value>` | No | Folder path as shown in the app; the leading / is optional. |
| `--search <value>` | No | Case-insensitive substring match against the resource name. |
| `--sort-by <value>` | No | Field used to sort the result. Do not rely on case-insensitive ordering when sorting by `name`. Defaults to "createdAt". Accepted values: `name`, `createdAt`, `updatedAt`. |
| `--sort-order <value>` | No | Sort direction. Defaults to "asc". Accepted values: `asc`, `desc`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `0`. |

</CommandTable>

API request and response schemas: [listTables](/api-reference/tables/listTables).

## Imports

### Import a CSV, into a new table by default

Choose exactly one source: a local CSV path or `--file-id`. For a new table imported with `--file-id`, supply `--name`. With `--table-id`, omit the new-table `--name` and `--folder` flags; `--mode`, `--mapping`, and `--create-columns` apply only to an existing table.

**Replace mode deletes all existing rows before loading the CSV and cannot be undone.** It requires `--yes`; cancellation leaves only the rows already imported.

The command watches the import by default. `--no-wait` returns a queued receipt. A completed import can still report `rowsRejected`, `cellsRejected`, and `rejectedSamples`; inspect them before accepting the result.

```bash
sim tables import [path] [options]
```

**Arguments**

<CommandTable>

| Argument | Required | Description |
| --- | --- | --- |
| `path` | No | Local CSV file to import; choose exactly one source: this path or --file-id |

</CommandTable>

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--name <name>` | Conditional | Name for a new table: letters, numbers, and underscores. A local CSV defaults to its sanitized filename; required with --file-id unless --table-id names an existing table. |
| `--table-id <id>` | No | Import into this existing table instead of creating one. |
| `--mode <append\|replace>` | No | How to write into --table-id (default: append). Accepted values: `append`, `replace`. |
| `--folder <path>` | No | Folder path for the new table, as shown in the app. |
| `--file-id <id>` | No | Import a file already in the workspace instead of a local path. |
| `--mapping <json\|@file>` | No | Column mapping (--table-id only). |
| `--create-columns <json\|@file>` | No | Columns to create (--table-id only). |
| `--timezone <iana>` | No | Timezone for date parsing, e.g. America/New_York. |
| `-y, --yes` | Conditional | Confirm this destructive operation (required with --mode replace). |
| `--no-wait` | No | Return once the import is queued instead of watching it. |

</CommandTable>

API request and response schemas: [createTableImport](/api-reference/tables/createTableImport), [createTableImportPartUrls](/api-reference/tables/createTableImportPartUrls), [completeTableImport](/api-reference/tables/completeTableImportUpload), [cancelTableImport](/api-reference/tables/cancelTableImport), [getTableImport](/api-reference/tables/getTableImport).
