Create and manage code-backed tools that agents can call.

`sim custom-tools` is also spelled `sim custom-tool`.

These commands accept the [global options](/cli/commands#global-options).

## List custom tools

```bash
sim custom-tools list [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--search <value>` | No | Case-insensitive substring match against the tool title. |
| `--sort-by <value>` | No | Field used to sort the result. Defaults to "createdAt". Accepted values: `title`, `createdAt`, `updatedAt`. |
| `--sort-order <value>` | No | Sort direction. Defaults to "desc". Accepted values: `asc`, `desc`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `0`. |

</CommandTable>

API request and response schemas: [listCustomTools](/api-reference/custom-tools/listCustomTools).

## Create custom tool

```bash
sim custom-tools create [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--title <value>` | Yes | Display title, unique within the workspace. |
| `--schema <json\|@file>` | Yes | OpenAI function schema: &#123;"type":"function","function":&#123;"name":"...","parameters":&#123;"type":"object","properties":&#123;&#125;&#125;&#125;&#125; (JSON, or @path / @- to read a file or stdin). |
| `--code <value>` | Yes | Tool implementation executed in the sandboxed function runtime. |

</CommandTable>

API request and response schemas: [createCustomTool](/api-reference/custom-tools/createCustomTool).
