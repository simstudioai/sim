List profiles and add a workspace profile that shares a stored login.

Adding a profile reuses the active stored login and selects a default workspace. Supply `--workspace` when running without an interactive terminal.

`sim profiles` is also spelled `sim profile`.

These commands accept the [global options](/cli/commands#global-options).

## List configured profiles

```bash
sim profiles list
```

## Add a workspace profile that shares the active stored login

```bash
sim profiles add <name> [options]
```

**Arguments**

<CommandTable>

| Argument | Required | Description |
| --- | --- | --- |
| `name` | Yes | Name for the new profile |

</CommandTable>

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `-w, --workspace <id>` | No | Existing workspace to use; omit for an interactive picker. |

</CommandTable>

API request and response schemas: [getWorkspace](/api-reference/workspaces/getWorkspace), [listWorkspaces](/api-reference/workspaces/listWorkspaces).
