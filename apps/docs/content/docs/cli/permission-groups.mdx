Manage organization permission groups, their configuration, and member assignments.

Use the linked API request schema for the supported `--config` keys. Supplied arrays replace their entire lists; omitted settings remain unchanged on update.

`sim permission-groups` is also spelled `sim permission-group`.

These commands accept the [global options](/cli/commands#global-options).

## Group configuration

### List permission groups

OAuth login or personal API key required.

```bash
sim permission-groups list [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--organization <value>` | Yes | Organization identifier. |
| `--search <value>` | No | Case-insensitive substring match against the group name. |
| `--sort-by <value>` | No | Field used to sort the result. Do not rely on case-insensitive ordering when sorting by `name`. Defaults to "createdAt". Accepted values: `name`, `createdAt`, `updatedAt`. |
| `--sort-order <value>` | No | Sort direction. Defaults to "desc". Accepted values: `asc`, `desc`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `0`. |

</CommandTable>

API request and response schemas: [listPermissionGroups](/api-reference/permission-groups/listPermissionGroups).

### Create permission group

OAuth login or personal API key required.

```bash
sim permission-groups create [options]
```

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--organization <value>` | Yes | Organization identifier. |
| `--name <value>` | Yes | Group name, unique within the organization. |
| `--description <value>` | No | Optional group description. |
| `--config <json\|@file>` | No | Group settings to set. Omitted keys use the default permission configuration. (JSON, or @path / @- to read a file or stdin). |
| `--default` | No | Whether the group is the organization default. Only one group can be the default. |
| `--no-default` | No | Send --default as false. |
| `--workspace-ids <json\|@file>` | Conditional | Workspace IDs targeted by a non-default group. Required when creating a non-default group; omit for a default group. (JSON, or @path / @- to read a file or stdin). |

</CommandTable>

API request and response schemas: [createPermissionGroup](/api-reference/permission-groups/createPermissionGroup).

### Update permission group

OAuth login or personal API key required.

```bash
sim permission-groups update <groupId> [options]
```

**Arguments**

<CommandTable>

| Argument | Required | Description |
| --- | --- | --- |
| `groupId` | Yes | Permission group identifier. |

</CommandTable>

**Options**

<CommandTable>

| Option | Required | Description |
| --- | --- | --- |
| `--organization <value>` | Yes | Organization identifier. |
| `--name <value>` | No | Group name, unique within the organization. |
| `--description <value>` | No | Group description. Null or an empty string clears it; omission leaves it unchanged. (--description null sends the word, not JSON null). |
| `--config <json\|@file>` | No | Patch of group settings. Omitted keys remain unchanged; each supplied array replaces that entire list. (JSON, or @path / @- to read a file or stdin). |
| `--default` | No | Whether the group is the organization default. Only one group can be the default. |
| `--no-default` | No | Send --default as false. |
| `--workspace-ids <json\|@file>` | No | Workspace identifiers for a non-default group. Required on creation; an empty update makes the group inactive. (JSON, or @path / @- to read a file or stdin). |

</CommandTable>

API request and response schemas: [updatePermissionGroup](/api-reference/permission-groups/updatePermissionGroup).

<CommandTable>

### Bulk add permission group members

**Options**

<CommandTable>
