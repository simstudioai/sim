`sim mcp-servers` is also spelled `sim mcp-server`.

Every command below also accepts the [global options](/cli/commands#global-options).

## sim mcp-servers create

Create MCP Server

```bash
sim mcp-servers create [options]
```

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--name <value>` | Yes | Set name. |
| `--description <value>` | No | Set description. |
| `--transport <value>` | No | Set transport. Accepted values: `streamable-http`. |
| `--url <value>` | Yes | Set url. |
| `--auth-type <value>` | No | Set auth type. Accepted values: `none`, `headers`, `oauth`. |
| `--headers <json\|@file>` | No | Set headers (JSON, or @path / @- to read a file or stdin). |
| `--timeout <value>` | No | Set timeout. |
| `--retries <value>` | No | Set retries. |
| `--enabled` | No | Set enabled. |
| `--no-enabled` | No | Set enabled to false. |
| `--oauth-client-id <value>` | No | Set oauth client id. |
| `--oauth-client-secret <value>` | No | Set oauth client secret. |

## sim mcp-servers list

List MCP Servers

```bash
sim mcp-servers list [options]
```

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--search <value>` | No | Set search. |
| `--sort-by <value>` | No | Set sort by. Accepted values: `name`, `createdAt`, `updatedAt`. |
| `--sort-order <value>` | No | Set sort order. Accepted values: `asc`, `desc`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `100`. |
