`sim workspaces` is also spelled `sim workspace`.

Every command below also accepts the [global options](/cli/commands#global-options).

## sim workspaces get

Get Workspace

```bash
sim workspaces get
```

## sim workspaces members

List workspace members

```bash
sim workspaces members [options]
```

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `100`. |
