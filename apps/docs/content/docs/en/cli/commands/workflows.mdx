`sim workflows` is also spelled `sim workflow`.

Every command below also accepts the [global options](/cli/commands#global-options).

## sim workflows runs cancel

Cancel a running workflow run

```bash
sim workflows runs cancel <runId> [options]
```

**Arguments**

| Argument | Required |
| --- | --- |
| `runId` | Yes |

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--workflow <workflowId>` | Yes | Workflow ID. |

## sim workflows runs get

Show run status (requested outputs are included in JSON or YAML output)

```bash
sim workflows runs get <runId> [options]
```

**Arguments**

| Argument | Required |
| --- | --- |
| `runId` | Yes |

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--workflow <workflowId>` | Yes | Workflow ID. |
| `--include-output` | No | Include the final output in JSON or YAML output. |
| `--select-output <value...>` | No | Include blockName.field values in JSON or YAML output (e.g. agent_1.content) (space-separated, or @path / @- with one value per line). |

## sim workflows runs list

List runs for a workflow

```bash
sim workflows runs list [options]
```

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--workflow <workflowId>` | Yes | Workflow ID. |
| `--status <value>` | No | Set status. Accepted values: `pending`, `running`, `completed`, `failed`, `cancelled`, `paused`. |
| `--trigger <value>` | No | Set trigger. |
| `--start-date <value>` | No | Set start date. |
| `--end-date <value>` | No | Set end date. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `100`. |
| `--order <value>` | No | Set order. Accepted values: `asc`, `desc`. |

## sim workflows run

Run a deployed workflow

```bash
sim workflows run <id> [options]
```

**Arguments**

| Argument | Required |
| --- | --- |
| `id` | Yes |

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--input <json\|@file>` | No | Trigger input as JSON (JSON, or @path / @- to read a file or stdin). |
| `--async` | No | Queue the run and return immediately. |
| `--execution-timeout-seconds <value>` | No | Set execution timeout seconds. |
| `--select-output <value...>` | No | Return blockName.field values (e.g. agent_1.content); missing fields are omitted (space-separated, or @path / @- with one value per line). |
| `--include-file-base64` | No | Set includeFileBase64. |
| `--no-include-file-base64` | No | Set includeFileBase64 to false. |
| `--base64-max-bytes <value>` | No | Set base64 max bytes. |
