`sim custom-tools` is also spelled `sim custom-tool`.

Every command below also accepts the [global options](/cli/commands#global-options).

## sim custom-tools create

Create Custom Tool

```bash
sim custom-tools create [options]
```

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--title <value>` | Yes | Set title. |
| `--schema <json\|@file>` | Yes | OpenAI function schema: &#123;"type":"function","function":&#123;"name":"...","parameters":&#123;"type":"object","properties":&#123;&#125;&#125;&#125;&#125; (JSON, or @path / @- to read a file or stdin). |
| `--code <value>` | Yes | Set code. |

## sim custom-tools delete

Delete Custom Tool


**Arguments**

| Argument | Required |
| --- | --- |
| `id` | Yes |

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `-y, --yes` | No | Skip the confirmation. |

## sim custom-tools list

List Custom Tools

```bash
sim custom-tools list [options]
```

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--search <value>` | No | Set search. |
| `--sort-by <value>` | No | Set sort by. Accepted values: `title`, `createdAt`, `updatedAt`. |
| `--sort-order <value>` | No | Set sort order. Accepted values: `asc`, `desc`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `100`. |
