`sim files` is also spelled `sim file`.

Every command below also accepts the [global options](/cli/commands#global-options).

## sim files batch-delete

Delete several files at once

```bash
sim files batch-delete [options]
```

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--file-ids <value...>` | Yes | Set file ids (space-separated, or @path / @- with one value per line). |
| `-y, --yes` | No | Skip the confirmation. |

## sim files create

Create File

```bash
sim files create [options]
```

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--name <value>` | Yes | Set name. |
| `--content-type <value>` | No | Set content type. |
| `--folder <value>` | No | Folder path; the leading / is optional. |
| `--content <value>` | No | Set content. |
| `--encoding <value>` | No | Set encoding. Accepted values: `utf-8`, `base64`. |

Also available as `sim files folders ls`.

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--parent <value>` | No | Direct parent folder path. |

| `--sort-by <value>` | No | Set sort by. Accepted values: `name`, `createdAt`, `updatedAt`. |
| `--sort-order <value>` | No | Set sort order. Accepted values: `asc`, `desc`. |

## sim files share set

Enable or disable sharing for a file

```bash

```

**Arguments**

| Argument | Required |
| --- | --- |
| `fileId` | Yes |

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--is-active <true\|false>` | Yes | Set isActive. Accepted values: `true`, `false`. |
| `--auth-type <value>` | No | Set auth type. Accepted values: `public`, `password`, `email`, `sso`. |
| `--password <value>` | No | Set password. |
| `--allowed-emails <value...>` | No | Set allowed emails (space-separated, or @path / @- with one value per line). |

## sim files list

List Files

```bash
sim files list [options]
```

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--folder <value>` | No | Folder path; the leading / is optional. |
| `--scope <value>` | No | Set scope. Accepted values: `active`, `archived`. |
| `--search <value>` | No | Set search. |
| `--sort-by <value>` | No | Set sort by. Accepted values: `name`, `size`, `uploadedAt`, `updatedAt`. |
| `--sort-order <value>` | No | Set sort order. Accepted values: `asc`, `desc`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `100`. |
