`sim credentials` is also spelled `sim credential`.

Every command below also accepts the [global options](/cli/commands#global-options).

## sim credentials delete

Disconnect Credential

```bash
sim credentials delete <credentialId> [options]
```

**Arguments**

| Argument | Required |
| --- | --- |
| `credentialId` | Yes |

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `-y, --yes` | No | Skip the confirmation. |

## sim credentials providers list

List Credential Providers

```bash
sim credentials providers list [options]
```

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--search <value>` | No | Set search. |

## sim credentials list

List Credentials

```bash
sim credentials list [options]
```

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--type <value>` | No | Set type. Accepted values: `oauth`, `service_account`. |
| `--provider-id <value>` | No | Set provider id. |
| `--search <value>` | No | Set search. |
| `--sort-by <value>` | No | Set sort by. Accepted values: `displayName`, `createdAt`, `updatedAt`. |
| `--sort-order <value>` | No | Set sort order. Accepted values: `asc`, `desc`. |
| `--limit <n>` | No | Maximum items to return (0 for everything). Defaults to `100`. |

## sim credentials create

Create a service-account credential using its discovered provider schema

```bash
sim credentials create <providerId> [options]
```

**Arguments**

| Argument | Required |
| --- | --- |
| `providerId` | Yes |

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--name <displayName>` | Yes | Name shown for the credential in Sim. |
| `--credentials <json\|@file>` | Yes | Provider credentials as JSON (or @path / @- to read a file or stdin). |
| `--description <description>` | No | Optional credential description. |
| `--id <credentialId>` | No | Client-generated credential ID when provider discovery requires it. |

**Arguments**

| Argument | Required |
| --- | --- |
| `providerId` | Yes |

**Options**

| Option | Required | Description |
| --- | --- | --- |
| `--name <displayName>` | Yes | Name shown for the new credential in Sim. |
