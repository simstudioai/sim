## Usage Instructions

Connect to the Google Admin SDK to run joiner, mover, and leaver work: create and suspend users, move them between org units, reset passwords, grant and revoke admin roles, wipe or block devices, and read audit and usage reports.



## Actions

### Google Workspace Admin List Users

List Google Workspace directory users for a customer or domain

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `customer` | string | No | Customer ID, or "my_customer" for the authenticated account \(default\) |
| `domain` | string | No | Domain to list users from \(e.g. example.com\). Used instead of customer |
| `query` | string | No | Directory search query filtering the results \(e.g. "orgUnitPath=/Sales" or "email:jane*"\) |
| `maxResults` | number | No | Maximum number of users to return \(1-500\). Example: 100 |
| `pageToken` | string | No | Token for fetching the next page of results |
| `orderBy` | string | No | Field to sort by: EMAIL, FAMILY_NAME, or GIVEN_NAME |
| `sortOrder` | string | No | Sort direction: ASCENDING or DESCENDING |
| `projection` | string | No | Fields to include for each user: BASIC, CUSTOM, or FULL |
| `showDeleted` | boolean | No | Return recently deleted users instead of active ones |
| `viewType` | string | No | Whether to read the admin_view or the domain_public view of each user |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `users` | json | Array of Directory API User resources |
|   ↳ `id` | string | Unique user ID |
|   ↳ `primaryEmail` | string | Primary email address |
|   ↳ `name` | json | Name object with givenName, familyName, fullName |
|   ↳ `isAdmin` | boolean | Whether the user is a super administrator |
|   ↳ `suspended` | boolean | Whether the account is suspended |
|   ↳ `orgUnitPath` | string | Org unit the user belongs to |
|   ↳ `lastLoginTime` | string | Last login timestamp |
| `nextPageToken` | string | Token for fetching the next page of results |

### Google Workspace Admin Reset Password

Set a new password on a Google Workspace user account, optionally forcing a password change at next sign-in

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `userKey` | string | Yes | User whose password is being reset, given as their primary email address, alias email address, or unique user ID |
| `password` | string | Yes | New password. 8-100 ASCII characters in clear text, or a valid hash when hashFunction is set. Never returned by the API |
| `changePasswordAtNextLogin` | boolean | No | Force the user to choose a new password at next sign-in. Has no effect for users signing in through a third-party identity provider |
| `hashFunction` | string | No | Hash format of the supplied password: MD5, SHA-1, or crypt. Omit when sending a clear-text password |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `user` | json | The updated Directory API User resource. The password is never returned |
|   ↳ `id` | string | Unique user ID |
|   ↳ `primaryEmail` | string | Primary email address |
|   ↳ `changePasswordAtNextLogin` | boolean | Whether the user must change their password at next sign-in |
