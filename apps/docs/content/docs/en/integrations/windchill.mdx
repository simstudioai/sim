## Usage Instructions

Integrate PTC Windchill document management into your workflow. Read and update WT.Document metadata, perform version and lifecycle actions, and transfer primary content and attachments.



## Actions

### Windchill List Documents

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `operation` | string | Windchill operation that was executed |
| `document` | json | Windchill document |
| `documents` | json | Windchill documents |
| `structure` | json | Document structure links |
| `states` | json | Valid lifecycle states |
| `content` | json | Primary-content metadata |
| `attachments` | json | Attachment metadata |
| `pageInfo` | json | OData pagination information |
| `affectedIds` | array | Affected document identifiers |
| `uploadedFileNames` | array | Uploaded file names |
| `file` | file | Downloaded file |
| `fileName` | string | Downloaded file name |
| `mimeType` | string | Downloaded content MIME type |
