[Photon](https://photon.codes) gives your workflows a real iMessage presence. Photon runs the iMessage line in its cloud, so messages send and receive from a genuine blue-bubble number with no Mac to babysit — and the full conversation surface is available to automation, not just plain text.

## Why Photon?

- **Apple-native depth**: tapback reactions, threaded replies, screen and bubble effects, native polls, group chat administration, shared chat backgrounds, and typing indicators — the things that make a conversation feel human on an iPhone.
- **True unsend and edit**: retract or correct a sent message on the recipient's device, not just in an API's records.
- **Attachments as files**: photos and documents texted to your number download straight into the workflow as files ready for extraction, storage, or classification.
- **Typed, verified events**: inbound messages, tapbacks, and read receipts arrive as signed webhooks with structured fields — signatures are verified with Photon's own scheme and replayed deliveries are deduplicated.
- **One-click wiring**: enter your project credentials and Sim registers the webhook with Photon on deploy, stores the signing secret, and cleans up when the trigger is removed.

## Using iMessage (Photon) in Sim

With 20 operations spanning conversation (send, media, voice memos, tapbacks, polls, typing, read receipts), message lifecycle (edit, unsend, fetch, attachment download), group administration (create, rename, photo, membership), and presence (contact card, chat backgrounds) — plus four triggers for inbound messages, tapbacks, read receipts, and a catch-all — workflows can hold a conversation end to end: greet a new lead, react to their reply with a tapback, send a photo, run a poll in a group, and retract a mistake before anyone screenshots it.

Get a project ID and secret at [app.photon.codes](https://app.photon.codes). The same credentials power both the tools and automatic webhook registration.

## Usage Instructions

Send iMessages from a Photon-managed number and trigger workflows on inbound messages, tapbacks, and read receipts. Photon runs the iMessage line, so no Mac is required. Beyond text, workflows can send media and voice memos, react with tapbacks, edit and unsend messages, run native polls, manage group chats, and download received attachments.



## Actions

### Send iMessage

Send an iMessage to a phone number or email address, or into an existing chat, optionally as a reply or with a screen or bubble effect

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `projectId` | string | Yes | Photon project ID from app.photon.codes |
| `projectSecret` | string | Yes | Photon project secret from app.photon.codes |
| `to` | string | Yes | Where to send: a phone number in E.164 form \(e.g. +14155551234\), an Apple ID email, or a chat ID from an iMessage trigger. A chat ID is the only way to reach a group chat. |
| `text` | string | Yes | Message text to send. iMessage is plain text, so Markdown is not rendered. |
| `effectName` | string | No | Send with an iMessage effect: balloons, celebration, confetti, echo, fireworks, gentle, heart, invisible, lasers, loud, slam, sparkles, or spotlight |
| `replyToMessageId` | string | No | Message ID to reply to inline \(threaded reply\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `messageId` | string | Identifier of the sent message |
| `chatId` | string | Chat GUID the message was sent to. Pass this back to target the same chat. |
| `timestamp` | string | ISO 8601 time the message was sent |

## Triggers

A **Trigger** is a block that starts a workflow when an event happens in this service.

### Photon Any Event

Trigger workflow on every inbound Photon delivery: messages, tapbacks, and read receipts

#### Configuration

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `triggerProjectId` | string | Yes | Project ID from app.photon.codes, used to register the webhook. |
| `triggerProjectSecret` | string | Yes | Project secret from app.photon.codes. Also used to clean up the webhook when the trigger is removed. |
| `triggerSenderAllowlist` | string | No | Comma-separated phone numbers or Apple ID emails. When set, only deliveries from these senders fire the workflow. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `messageId` | string | Unique identifier of the delivered record \(use to deduplicate\) |
| `contentType` | string | Content arm of the delivery: text, attachment, reaction, read, and so on |
| `text` | string | Message text when the delivery carries any |
| `senderId` | string | Phone number or Apple ID email of the actor |
| `chatId` | string | Chat GUID the event happened in |
| `chatType` | string | Conversation type, dm or group |
| `timestamp` | string | ISO 8601 event time |
| `raw` | string | Complete raw webhook payload from Photon as a JSON string |
