Use **Search** when you want to find a page, message, or file in your connected apps. Start with a project name or a phrase you remember, then narrow the results.

Your organization must enable Search and make a source available to you. [Connect your account](/search/connect-your-account) if that source requires a personal connection.

## Find a document

1. Open **Search** in the organization sidebar. If you're in a workspace, open the workspace menu and select **Back to organization** first.
2. Enter a title, project name, or distinctive phrase, such as `product requirements`.
3. Press **Enter** or select the arrow to search.

Read the title and excerpt to find the relevant result. Each result shows its source, with an author and date when available. Select the title to open the original.

## Narrow the results

Use the filters beneath the search field:

| Filter | Use it to |
| --- | --- |
| **All sources** | Choose one app, such as Confluence or Google Drive. |
| **Any time** | Search without a date restriction. |
| **Past week** or **Past month** | Focus on recently updated content. |
| **Custom range** | Choose a start and end date. |

Filters update the results. Return to **All sources** and **Any time** to broaden the search again.

If a query is too broad, add a detail you know: try `product requirements template` instead of `requirements`. Search coverage and the dates available depend on the source.

## Use a result

Open the **…** menu beside a result:

- **Summarize** starts a Search conversation about that document. Ask a follow-up to explore it further.
- **Copy link** copies the original source link. Anyone you send it to still needs access in that app.

For an answer that combines several documents, [ask a question in Search](/search/ask-questions).

## Return to something you found

Open **Search** again to see **Recently viewed** sources and **Recent searches**. Select a source to reopen it, or a query to search again.

This history is private to your account in the current organization. **Clear history** removes both lists.

## If you can't find it

- **No results:** try a shorter phrase, remove the date filter, or choose **All sources**. Confirm that your connected account can open the original content.
- **Some apps couldn't be searched:** the results shown may be incomplete. Retry, or open **Integrations** to check whether an account needs reconnecting.
- **Search couldn't run:** select **Try again**. If the problem continues, check your connection in **Integrations**.
- **A source is missing:** ask your organization admin whether it is available to you.

An empty result does not prove a document is absent. Provider search limits and your organization's source settings can affect what you find. See [access and freshness](/search#access-and-freshness).
