---
title: Generic Secrets
description: Store shared or personal secrets for organization Home conversations
---

Generic Secrets stores values that Sim can use in code and requests from an organization **Home** conversation, including **Plan** when available. It uses the same [secrets editor as workspaces](/platform/credentials) and does not connect an external account or add searchable documents.

## Add the source

An organization admin opens **Settings → Sources → Add source → Generic Secrets** and chooses a mode:

| Mode | Manage values | Use in Home |
| --- | --- | --- |
| **Organization** | Admins open **Secrets** from the source in Settings. | Members with Home access use shared values. Members cannot open the editor to view them. |
| **Member** | Each person opens **Integrations → Generic Secrets → Manage secrets**. | Each person uses only their own values in the organization. |

Only the selected mode is active. To change it, select **Configure** on the source.

## Use a secret

1. Save a name and value in the editor.
2. Open **Home** in the organization sidebar and ask Sim to run code that needs that secret.
3. Sim sees available names and mounts the names needed by `run_code` or `run_function` as environment variables. Code can use them in requests such as `curl` without putting values in the prompt.

In an organization conversation targeting a workspace, an organization secret takes precedence over a workspace secret with the same name. Member mode resolves the current member's values and cannot use another member's secrets.

**Search**, including **Assistant**, Search MCP, and Sim Search in Slack cannot mount these values. Workspace secrets remain a separate resource.

## Remove the source

Removing the source deletes its organization and member secrets. Review the confirmation before removing it.
