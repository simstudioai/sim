## Your workspace [#workspace-resources]

A workspace holds the resources your team and agents use:

| Resource | Purpose |
| --- | --- |
| **[Workflows](/workflows)** | Executable logic made of connected blocks. Use Agent blocks for model reasoning and tools for actions such as sending email or querying an API. |
| **[Tables](/tables)** | Structured rows that workflows can read, update, and process. |
| **[Files](/files)** | Documents and media you upload, create, and share with agents. |
| **[Knowledge bases](/knowledgebase)** | Searchable documents. Retrieve relevant passages for an agent to use in its answers. |
| **[Logs](/logs-debugging)** | Run records and block inputs, outputs, errors, timing, and costs. |

[Deploy a workflow](/workflows/deployment) to make it available through an API, a chat interface, or an MCP server. MCP (Model Context Protocol) lets AI applications discover and call tools exposed by a server.

## Models and integrations

Find supported services in the [integration catalog](/integrations). Add them as workflow blocks or tools an Agent can call.

For tools outside the catalog, connect an [external MCP server](/agents/mcp) or create a [custom tool](/agents/custom-tools). Configure the credentials and permissions each service requires.

## Choose a deployment

- **Sim Cloud:** Sign in at [sim.ai](https://www.sim.ai) to use the managed service.
- **Self-hosted:** Run Sim on your infrastructure with [Docker Compose](/platform/self-hosting/docker) or [Kubernetes](/platform/self-hosting/kubernetes). You can connect local models through Ollama or vLLM. Chat and external integrations can still require network access.

The core source is available on [GitHub](https://github.com/simstudioai/sim) under the Apache 2.0 license. Enterprise features use a separate license that requires an active Enterprise subscription for production use. See [self-hosting](/platform/self-hosting) for installation requirements and configuration.
