{/* MANUAL-CONTENT-START:intro */}
[Ramp](https://ramp.com/) helps businesses manage corporate cards, expenses, bills, and reimbursements.

With the Ramp block, you can:

- **Review spending**: Read company balances, transactions, vendors, and employee details.
- **Inspect cards**: List and read physical and virtual cards, including ownership and suspension status.
- **Prepare finance reviews**: Read bills and reimbursements with date, status, and employee filters.
- **Document expenses**: Read and add memos for transaction records.

Save your Ramp developer app's client ID and client secret as a credential, then select it in the Ramp block. Use a production app owned by your business with the **Client Credentials** grant enabled. This connection accesses your own business's Ramp data; sandbox credentials are not supported.

Enable these scopes on your app: `business:read`, `users:read`, `transactions:read`, `cards:read`, `vendors:read`, `bills:read`, `reimbursements:read`, `memos:read`, and `memos:write`. Sim requests these scopes when it obtains an access token and automatically obtains a new token when needed. You do not need a redirect URI or a Sim-owned OAuth application. See [Ramp's authorization guide](https://docs.ramp.com/developer-api/v1/authorization) for app setup and permissions.

The OAuth deployment settings below apply to the optional browser consent flow. They are not required when you save your own app's client credentials.

List operations return one page at a time, with 2–100 results per page. Pass `nextCursor` as the pagination cursor to continue. Money outputs preserve Ramp's currency and minor-unit fields; avoid combining different currencies.

In Sim, the Ramp block lets your agents prepare spend reports, organize bill and reimbursement reviews, inspect employee cards, and save approved transaction memos.
{/* MANUAL-CONTENT-END */}


## Usage Instructions

Connect Ramp to your agents to review company balances, employees, card transactions, physical and virtual cards, vendors, bills, and reimbursements. Add transaction memos and paginate through records with up to 100 results per request.

## OAuth Scopes

Sim requests these scopes when someone connects a Ramp account. On a self-hosted deployment, register your own app with the provider using the settings below. See [Integrations & OAuth](/platform/self-hosting/integrations-oauth) for the full setup.

| Setting | Value |
| ------- | ----- |
| Redirect URI | `<NEXT_PUBLIC_APP_URL>/api/auth/oauth2/callback/ramp` |
| Environment variables | `RAMP_CLIENT_ID`, `RAMP_CLIENT_SECRET` |

| Scope | Description |
| ----- | ----------- |
| `business:read` | View Ramp business details and balances |
| `users:read` | View Ramp users and roles |
| `transactions:read` | View Ramp transactions |
| `cards:read` | View Ramp physical and virtual card details |
| `vendors:read` | View Ramp vendors |
| `bills:read` | View Ramp bills |
| `reimbursements:read` | View Ramp reimbursements |
| `memos:read` | View Ramp transaction memos |
| `memos:write` | Create and update Ramp transaction memos |
