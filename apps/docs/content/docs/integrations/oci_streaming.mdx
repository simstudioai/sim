## Usage Instructions

Use native OCI REST APIs with a reusable API signing-key service account. Manage streams and pools, publish one bounded batch, read one batch using expiring cursors, explicitly commit consumer groups, and inspect work requests. Message operations require GetStream permission for authenticated endpoint discovery. Offsets remain decimal strings and delivery is at least once. Group cursors default to manual commits. No Kafka client, continuous consumer, automatic polling, or private endpoint provisioning is included.



## Actions

### OCI Streaming Change Stream Compartment

Move a stream into the destination compartment and its default stream pool.

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |

| `requestId` | string | No | Optional Oracle request identifier, up to 255 printable characters. |

| `compartmentId` | string | Yes | Compartment OCID. For list/create stream, supply exactly one of compartmentId or streamPoolId. |

### OCI Streaming Get Messages

Read one bounded batch, including empty batches, and return nextCursor. No polling or retries. With commitOnGet enabled, reads can commit the prior batch.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `ociCredential` | string | Yes | Reusable OCI API signing-key service account. Private keys stay in the foundation. |
| `ociRegion` | string | No | Optional OCI region override; defaults to the credential region. |
| `requestId` | string | No | Optional Oracle request identifier, up to 255 printable characters. |
| `streamId` | string | Yes | Stream OCID. Message operations also require GetStream permission for authenticated endpoint discovery. |
| `cursor` | string | Yes | Opaque cursor, expiring after five minutes. Use the latest read, commit, or heartbeat cursor; never decode or recreate it automatically. |
| `limit` | number | No | Maximum messages in one batch: default 100, maximum 1,000. Empty batches still return nextCursor. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `status` | number | HTTP success status; inspect lifecycle state or work request for asynchronous completion. |
| `requestId` | string | Oracle request identifier. |
| `etag` | string | Resource ETag when provided by Oracle. |
| `workRequestId` | string | Asynchronous work request OCID when provided by Oracle. |
| `messages` | array | One bounded batch; may be empty. |
|   ↳ `stream` | string | Stream identifier as returned by Oracle. |
|   ↳ `partition` | string | Partition identifier. |
|   ↳ `key` | string | Base64 key, or null. |
|   ↳ `value` | string | Base64 message value. |
|   ↳ `offset` | string | Exact partition-local decimal offset. |
|   ↳ `timestamp` | string | Append timestamp. |
| `nextCursor` | string | Next opaque message cursor, also returned for empty batches. Not an administrative page token. |
