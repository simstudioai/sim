Use [Tailscale](https://tailscale.com) to manage devices, users, device posture, DNS, policy files, keys, and tailnet settings.

## Authentication

Enter a Tailscale **API access token** in **API Access Token**. The block sends it using Bearer authentication. Create a personal token in the [Keys page of the admin console](https://login.tailscale.com/admin/settings/keys); personal tokens expire after 1–90 days and inherit the user's permissions.

An access token generated by a Tailscale OAuth client or federated identity also works. Generate that token using Tailscale's documented [trust credential flow](https://tailscale.com/docs/reference/trust-credentials), then supply the access token to the block. The block does not exchange client secrets or refresh expired tokens. For scheduled workflows, supply a fresh access token from your credential management workflow before it expires.

Device enrollment keys (`tskey-auth-`) and OAuth client secrets (`tskey-client-`) cannot authenticate these API requests. When using scoped OAuth access tokens, grant the scopes required by the selected endpoint in the [API reference](https://tailscale.com/api). Creating a tailnet-owned auth key with OAuth also requires device tags owned by that credential.

## Tailnet identifier [#tailnet-identifier]

Tailnet-scoped operations require a **Tailnet**: use `-` for the access token's default tailnet, the tailnet ID from General Settings, or a supported legacy tailnet name. Device- and user-scoped operations use their resource IDs directly.

## Device fields, filters, and keys

In advanced mode, select **All** device fields to include route, connectivity, SSH, and posture details. **Device Filters** accepts URL query syntax such as `isEphemeral=true&tags=tag:server`. Repeating a tag filter requires all specified tags. User lists can be filtered by relationship type and role.

**List Keys** returns active enrollment keys, API access tokens, and trust credentials. Use `keyType` and `userId` to identify the intended credentials before revoking them. **Include All Tailnet Keys** defaults to enabled; disable it to use the API's token-owner visibility rules.

## Policy and network changes

Use **Validate ACL** to validate JSON or HuJSON policy files, or run a JSON array of ACL tests, without changing the policy. Inspect `valid`, `message`, and `results`, since validation errors can be returned with HTTP 200. Pass the ETag from **Get ACL** to **Set ACL** to protect against concurrent edits.

List inputs accept comma-separated values or a JSON array of strings. Use `[]` to clear tags, enabled routes, nameservers, or search paths. **Set Split DNS** replaces every split DNS entry; **Update Split DNS** changes only specified entries and accepts `null` to remove a domain. **Set DNS Configuration** replaces the complete DNS configuration, including resolver options and preferences. **Update Tailnet Settings** updates only supplied settings; do not specify both `routeSelection` and `regionalRoutingOn`.

List endpoints return a single API response and do not support pagination. Sim applies its shared response byte limit before transforming the result.

## Actions

### Tailscale List Devices

List devices in the tailnet

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | Yes | Tailscale API access token or OAuth access token \(not an auth key or OAuth client secret\) |
| `tailnet` | string | Yes | Tailnet ID, legacy name, or "-" for the token’s default tailnet |
| `fields` | string | No | Device fields to return: default or all |
| `filters` | string | No | URL query filters for top-level device fields, e.g. isEphemeral=true&tags=tag:server |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `devices` | array | Devices in the tailnet |
|   ↳ `addresses` | array | Tailscale IP addresses |
|   ↳ `id` | string | Resource ID |
|   ↳ `nodeId` | string | Preferred device ID |
|   ↳ `user` | string | User who registered the device |
|   ↳ `name` | string | Device MagicDNS name |
|   ↳ `hostname` | string | Device machine name |
|   ↳ `clientVersion` | string | Tailscale client version |
|   ↳ `updateAvailable` | boolean | Whether a client update is available |
|   ↳ `os` | string | Operating system |
|   ↳ `created` | string | Creation timestamp |
|   ↳ `connectedToControl` | boolean | Whether the device is connected to the control server |
|   ↳ `lastSeen` | string | Last seen timestamp; a connected device may omit it |
|   ↳ `keyExpiryDisabled` | boolean | Whether device key expiry is disabled |
|   ↳ `expires` | string | Key expiration timestamp |
|   ↳ `authorized` | boolean | Whether the device is authorized |
|   ↳ `isExternal` | boolean | Whether the device is shared from another tailnet |
|   ↳ `multipleConnections` | boolean | Whether multiple devices are using the same node key |
|   ↳ `machineKey` | string | Machine public key |
|   ↳ `nodeKey` | string | Node public key |
|   ↳ `blocksIncomingConnections` | boolean | Whether incoming connections are blocked |
|   ↳ `enabledRoutes` | array | Approved subnet routes |
|   ↳ `advertisedRoutes` | array | Advertised subnet routes |
|   ↳ `clientConnectivity` | json | Connectivity report |
|     ↳ `endpoints` | array | Client's magicsock UDP IP:port endpoints \(IPv4 or IPv6\) |
|     ↳ `mappingVariesByDestIP` | boolean | 'true' if the host's NAT mappings vary based on the destination IP |
|     ↳ `latency` | json | Map of DERP server locations and their current latency |
|     ↳ `clientSupports` | json | Identifies features supported by the client |
|       ↳ `hairPinning` | boolean | This information is no longer tracked and will always be null |
|       ↳ `ipv6` | boolean | 'true' if the device OS supports IPv6, regardless of whether IPv6 internet connectivity is available |
|       ↳ `pcp` | boolean | 'true' if PCP port-mapping service exists on your router |
|       ↳ `pmp` | boolean | 'true' if NAT-PMP port-mapping service exists on your router |
|       ↳ `udp` | boolean | 'true' if UDP traffic is enabled on the current network; if 'false', Tailscale may be unable to make direct connections, and will rely on our DERP servers |
|       ↳ `upnp` | boolean | 'true' if UPnP port-mapping service exists on your router |
|   ↳ `tags` | array | Assigned tags |
|   ↳ `tailnetLockError` | string | Tailnet lock signature error |
|   ↳ `tailnetLockKey` | string | Tailnet lock public key |
|   ↳ `sshEnabled` | boolean | Whether Tailscale SSH is enabled |
|   ↳ `postureIdentity` | json | Device posture identity |
|     ↳ `serialNumbers` | array | Serial numbers |
|     ↳ `disabled` | boolean | Disabled |
|   ↳ `postureStatus` | json | Device posture status |
|     ↳ `passing` | boolean | Reports whether the device is passing this posture |
|     ↳ `impacting` | boolean | Whether the status of this posture affects the connectivity of the device |
|     ↳ `failingAssertions` | array | List of posture assertions the device is failing |
|   ↳ `isEphemeral` | boolean | Whether the device is ephemeral |
|   ↳ `distro` | json | Operating system distribution |
|     ↳ `name` | string | Operating system distribution name |
|     ↳ `version` | string | The operating system distribution version that the device is running |
|     ↳ `codeName` | string | The operating system distribution code name that the device is running |
| `count` | number | Number of returned items |

</ReferenceDetails>
