{/* MANUAL-CONTENT-START:intro */}
Use [Microsoft Teams](https://teams.microsoft.com) to read, send, update, or delete chat and channel messages, reply to threads, and add reactions. List teams, chats, channels, and their members to resolve destinations.

Switch to trigger mode to start a workflow from message notifications in a selected chat, or when the outgoing webhook is @mentioned in a channel. To mention a user, wrap the name in `<at>` tags, such as `<at>userName</at>`, and supply the mention details required by the action.

Chat subscriptions request creation and update notifications, but Sim deduplicates them by subscription and message ID within a seven-day window. Later edits may not start a separate workflow run.
{/* MANUAL-CONTENT-END */}

## OAuth scopes [#oauth-scopes]

Sim requests these scopes when someone connects a Microsoft Teams account. For a self-hosted deployment, register your own app with the provider using the settings below. See [Integrations and OAuth](/platform/self-hosting/integrations-oauth) for setup.

| Setting | Value |
| ------- | ----- |
| Redirect URI | `<NEXT_PUBLIC_APP_URL>/api/auth/oauth2/callback/microsoft-teams` |
| Environment variables | `MICROSOFT_CLIENT_ID`, `MICROSOFT_CLIENT_SECRET` |

| Scope | Description |
| ----- | ----------- |
| `openid` | Standard authentication |
| `profile` | Access profile information |
| `email` | Access email address |
| `User.Read` | Sign in and read your profile |
| `Chat.Read` | Read your Teams chat messages |
| `Chat.ReadWrite` | Read and write your Teams chat messages |
| `Chat.ReadBasic` | Read names and members of your Teams chats |
| `ChatMessage.Send` | Send chat messages |
| `Channel.ReadBasic.All` | Read channel names and descriptions |
| `ChannelMessage.Send` | Send channel messages |
| `ChannelMessage.Read.All` | Read channel messages |
| `ChannelMessage.ReadWrite` | Read and write channel messages |
| `ChannelMember.Read.All` | Read team channel members |
| `Group.Read.All` | Read all groups, memberships, and group content |
| `Group.ReadWrite.All` | Read and write all groups |
| `Team.ReadBasic.All` | Read team names and descriptions |
| `TeamMember.Read.All` | Read team members |
| `offline_access` | Access account when not using the application |
| `Files.Read` | Read OneDrive files |
| `Sites.Read.All` | Read documents and list items in all SharePoint sites |

## Use the block [#usage-instructions]

Read, write, update, and delete chat and channel messages. Reply to messages, add reactions, and list teams, chats, channels, and their members. Use trigger mode for message notifications in a selected chat, or an @mention of the outgoing webhook in a channel. Chat subscriptions request creation and update notifications, but Sim deduplicates them by subscription and message ID within a seven-day window. Later edits may not start a separate run. To mention users in messages, wrap their name in `<at>` tags: `<at>userName</at>`

### Microsoft Teams Chat

Trigger workflows from Microsoft Teams chat message notifications via Microsoft Graph subscriptions. Notifications share a seven-day deduplication window keyed by subscription and message ID, so later edits may not start a separate run.

#### Configuration

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `triggerCredentials` | string | Yes | This trigger requires microsoft teams credentials to access your account. |
| `triggerChatId` | string | Yes | The ID of the Teams chat to monitor |
| `includeAttachments` | boolean | No | Fetch hosted contents and upload to storage |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `message_id` | string | Message ID |
| `chat_id` | string | Chat ID |
| `from_name` | string | Sender display name |
| `text` | string | Message body \(HTML or text\) |
| `created_at` | string | Message timestamp |
| `attachments` | file[] | Uploaded attachments as files |
