[Checkr](https://checkr.com/) is a background screening platform for employment checks: criminal, motor vehicle, identity, education, and employment verifications, plus ongoing monitoring.

With the Checkr block, you can:

- **Start background checks**: Create candidates and send them a Checkr-hosted invitation, or order a report directly when you already collect their information and consent.
- **Track and read results**: Get reports, their estimated completion, progressive checkpoint status, verifications, address history, assessments, and the detailed results of each screening.
- **Adjudicate**: Engage reports, apply review actions to paused reports, manage report tags, and run the adverse action process from adverse items through cancellation.
- **Keep screening going**: Schedule recurring checks with subscriptions and enroll candidates in continuous criminal or motor vehicle monitoring.
- **Look up account setup**: Read packages, geos, hierarchy nodes, programs, counties, candidate documents, users, and account details, and create, update, or delete geos.
- **React to events**: Start workflows when reports, invitations, candidates, verifications, adverse actions, or continuous checks change.

To connect, create a secret API key in the Checkr Dashboard under **Account Settings > Developer Settings** and paste it into the block. Use a production key: Checkr's staging environment uses a different API host and is not supported, and triggers register live-environment webhooks.

Triggers register a webhook in Checkr when you deploy the workflow and verify every delivery's signature with your API key. Checkr allows at most two webhooks per account, and each deployed Checkr trigger uses one, so choose **All Events** when one workflow needs to handle several event types.

In Sim, the Checkr block lets your agents send background checks the moment a candidate is selected, summarize completed reports for recruiters, queue consider results for human review, and keep drivers and other regulated roles under continuous monitoring.

## Usage Instructions

Integrate Checkr into the workflow. Create and update candidates, send background check invitations, order and upgrade reports, read screening results and assessments, manage report tags, run the adverse action process, schedule recurring checks and continuous monitoring, look up packages, geos, nodes, programs, documents, and users, and react to report, invitation, candidate, verification, adverse action, and continuous check webhooks.
