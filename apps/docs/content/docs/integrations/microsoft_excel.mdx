{/* MANUAL-CONTENT-START:intro */}
Use [Microsoft Excel](https://www.microsoft.com/microsoft-365/excel) in Sim to manage worksheets, table rows, and cell ranges in `.xlsx` workbooks on OneDrive for Business or SharePoint. Discover worksheets and tables, add or update records, write formulas and number formats, apply formatting, and calculate workbook results.

Choose a Microsoft account with access to the workbook. SharePoint site browsing requires the `Sites.Read.All` permission; reconnect an existing account to consent to the added scope. Enter a workbook ID and, for SharePoint, its drive ID, or use the selectors.

Use **Create Session** when several operations work on the same workbook. Turn on **Save Changes** to persist edits, or leave it off for a temporary copy. Pass the returned `sessionId` to every operation in that sequence, then close the session. Requests without a session ID save their changes directly. List operations return one page and expose `top` and `skip`; increase `skip` by the page count until fewer than `top` items are returned. Range reads should use an explicit bounded range for large worksheets; returned cell values retain the existing trimming of trailing empty rows and columns, while formula and format matrices describe the full returned range.
{/* MANUAL-CONTENT-END */}

## OAuth scopes [#oauth-scopes]

Sim requests these scopes when someone connects a Microsoft Excel account. For a self-hosted deployment, register your own app with the provider using the settings below. See [Integrations and OAuth](/platform/self-hosting/integrations-oauth) for setup.

| Setting | Value |
| ------- | ----- |
| Redirect URI | `<NEXT_PUBLIC_APP_URL>/api/auth/oauth2/callback/microsoft-excel` |
| Environment variables | `MICROSOFT_CLIENT_ID`, `MICROSOFT_CLIENT_SECRET` |

| Scope | Description |
| ----- | ----------- |
| `openid` | Standard authentication |
| `profile` | Access profile information |
| `email` | Access email address |
| `Files.Read` | Read OneDrive files |
| `Files.ReadWrite` | Read and write OneDrive files |
| `Sites.Read.All` | Read documents and list items in all SharePoint sites |
| `offline_access` | Access account when not using the application |

### Add to Microsoft Excel Table

Add new rows to a Microsoft Excel table

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `sessionId` | string | No | Workbook session ID from Create Session. Omit for a sessionless request that saves changes. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `index` | number | Index of the first row that was added |
| `values` | array | Two-dimensional cell values; cells contain strings, numbers, booleans, or null. |
| `metadata` | object | Spreadsheet metadata |
|   ↳ `spreadsheetId` | string | The ID of the spreadsheet |
|   ↳ `spreadsheetUrl` | string | URL to access the spreadsheet |
