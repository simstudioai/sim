{/* MANUAL-CONTENT-START:intro */}
Use [Workday](https://www.workday.com/) to read workers and organizations, create pre-hires, hire employees, update worker fields, assign onboarding plans, process job changes or terminations, and retrieve compensation details.

Provide the Workday instance URL, tenant, and Integration System User credentials with permission for the required business processes. Hiring, job-change, and termination requests can be subject to your tenant's approvals; a returned event ID does not by itself prove that the business process completed.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Create pre-hires, hire employees, manage worker profiles, assign onboarding plans, handle job changes, retrieve compensation data, and process terminations.

## Actions

### Get Workday Worker

Retrieve a specific worker profile including personal, employment, and organization data.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `tenantUrl` | string | Yes | Workday instance URL \(e.g., https://wd5-impl-services1.workday.com) |
| `tenant` | string | Yes | Workday tenant name |
| `username` | string | Yes | Integration System User username |
| `password` | string | Yes | Integration System User password |
| `workerId` | string | Yes | Worker ID to retrieve \(e.g., 3aa5550b7fe348b98d7b5741afc65534\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `worker` | json | Worker profile with personal, employment, and organization data |

</ReferenceDetails>
