{/* MANUAL-CONTENT-START:intro */}
Use [Monday.com](https://monday.com/) to manage boards, groups, columns, items, and subitems. Read or search items by column values, create or update them, duplicate or move them between groups, and archive or delete them. Updates let a workflow post comments.

Webhook triggers start workflows when items are created, deleted, or moved; column or status values change; or updates are posted. Use these events to synchronize board activity with another system.
{/* MANUAL-CONTENT-END */}

Connection guides: [API tokens](/integrations/monday-service-account).

## OAuth scopes [#oauth-scopes]

Sim requests these scopes when someone connects a Monday.com account. For a self-hosted deployment, register your own app with the provider using the settings below. See [Integrations and OAuth](/platform/self-hosting/integrations-oauth) for setup.

| Setting | Value |
| ------- | ----- |
| Redirect URI | `<NEXT_PUBLIC_APP_URL>/api/auth/oauth2/callback/monday` |
| Environment variables | `MONDAY_CLIENT_ID`, `MONDAY_CLIENT_SECRET` |

| Scope | Description |
| ----- | ----------- |
| `boards:read` | Read boards, items, and columns |
| `boards:write` | Create and modify boards, items, and groups |
| `updates:read` | Read updates and comments |
| `updates:write` | Create and edit updates and comments |
| `webhooks:read` | Read webhook subscriptions |
| `webhooks:write` | Create and manage webhook subscriptions |
| `me:read` | Read your user profile |

## Use the block [#usage-instructions]

Read or manage boards, groups, columns, items, and subitems in Monday.com. Search items, change column values, move or archive items, post updates, and start workflows from supported board events.

## Triggers

| `columnTitle` | string | The title of the changed column |
