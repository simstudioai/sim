{/* MANUAL-CONTENT-START:intro */}
Use [Wealthbox](https://www.wealthbox.com/) to read and write client notes, contacts, and tasks. A workflow can turn meeting output into a note, retrieve client context, or create follow-up work.

Connect with OAuth or a supported [API access token](/integrations/wealthbox-service-account). Each credential uses the connected Wealthbox user's permissions. Contact writes create new contacts; note and task writes also support updates.
{/* MANUAL-CONTENT-END */}


Connection guides: [API access tokens](/integrations/wealthbox-service-account).

## OAuth scopes [#oauth-scopes]

Sim requests these scopes when someone connects a Wealthbox account. For a self-hosted deployment, register your own app with the provider using the settings below. See [Integrations and OAuth](/platform/self-hosting/integrations-oauth) for setup.

| Setting | Value |
| ------- | ----- |
| Redirect URI | `<NEXT_PUBLIC_APP_URL>/api/auth/oauth2/callback/wealthbox` |
| Environment variables | `WEALTHBOX_CLIENT_ID`, `WEALTHBOX_CLIENT_SECRET` |

| Scope | Description |
| ----- | ----------- |
| `login` | Access Wealthbox account |
| `data` | Access Wealthbox data |

## Use the block [#usage-instructions]

Read or write Wealthbox notes, contacts, and tasks with OAuth or a supported API access token.

## Actions

### Read Wealthbox Note

Read content from a Wealthbox note

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `noteId` | string | No | The ID of the note to read \(e.g., "11111"\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `success` | boolean | Operation success status |
| `output` | object | Note data and metadata |
|   ↳ `content` | string | Formatted note information |
|   ↳ `note` | object | Raw note data from Wealthbox |
|   ↳ `metadata` | object | Operation metadata |
|     ↳ `itemId` | string | ID of the note |
|     ↳ `noteId` | string | ID of the note |
|     ↳ `itemType` | string | Type of item \(note\) |

### Write Wealthbox Note

Create or update a Wealthbox note

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `content` | string | Yes | The main body of the note |
| `contactId` | string | No | ID of contact to link to this note \(e.g., "12345"\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `success` | boolean | Operation success status |
| `output` | object | Created or updated note data and metadata |
|   ↳ `note` | object | Raw note data from Wealthbox |
|   ↳ `success` | boolean | Operation success indicator |
|   ↳ `metadata` | object | Operation metadata |
|     ↳ `itemId` | string | ID of the created/updated note |
|     ↳ `noteId` | string | ID of the created/updated note |
|     ↳ `itemType` | string | Type of item \(note\) |
