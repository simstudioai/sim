{/* MANUAL-CONTENT-START:intro */}
Use [Telegram](https://telegram.org)'s Bot API to send messages, photos, videos, audio, animations, documents, locations, contacts, or polls. Message actions also edit, forward, copy, pin, delete, and react; chat actions retrieve chat or member details and show status indicators.

## Start workflows from Telegram messages

1. Send `/newbot` to [BotFather](https://t.me/BotFather) in Telegram and copy the bot token.
2. Add a Telegram trigger to your workflow and enter **Bot Token**.
3. Deploy the workflow. Sim registers the generated webhook URL with Telegram.
4. Send a message to the bot and inspect the workflow run. The trigger returns message and sender data, including the source chat ID.

Telegram registers one webhook per bot. Registering it elsewhere redirects delivery, so use a separate bot when workflows need independent webhook destinations. See the [Telegram bot tutorial](https://core.telegram.org/bots/tutorial).

The [webhook setup video](https://www.youtube.com/embed/9oKcJtQ0_IM) also demonstrates starting a run from an incoming message.

## Send messages to a Telegram group

1. Add the bot to the group and grant the permissions needed by the action.
2. Obtain the group's numeric chat ID from a bot message update, such as the trigger's `message.raw.chat.id`. Group IDs can be negative.
3. Add a Telegram action block, select **Send Message**, and set **Bot Token**, **Chat ID**, and **Message**.
4. Run the workflow and verify the message in the group.

The [group messaging video](https://www.youtube.com/embed/AG55LpUreGI) demonstrates the block configuration. Bot privacy settings affect which group messages Telegram delivers; receiving a command addressed to the bot can help verify the trigger before changing those settings.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Send, edit, forward, copy, pin, or delete messages; send media, locations, contacts, and polls; set reactions and chat actions; and inspect chats and members. Bot messages and events can start workflows.

## Actions

### Telegram Send Message

Send a text message through the Telegram Bot API. Markdown is converted to Telegram HTML before sending; the response includes the sent message and recipient chat.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `botToken` | string | Yes | Your Telegram Bot API Token |
| `chatId` | string | Yes | Telegram chat ID \(numeric, can be negative for groups\) |
| `text` | string | Yes | Message text to send |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `message` | string | Success or error message |
| `data` | object | Telegram message data |
|   ↳ `message_id` | number | Unique Telegram message identifier |
|   ↳ `from` | object | Sender information |
|     ↳ `id` | number | Sender user ID |
|     ↳ `is_bot` | boolean | Whether the sender is a bot |
|     ↳ `first_name` | string | Sender first name |
|     ↳ `username` | string | Sender username, when available |
|   ↳ `chat` | object | Recipient chat information |
|     ↳ `id` | number | Recipient chat ID |
|     ↳ `first_name` | string | Chat first name, for private chats |
|     ↳ `username` | string | Chat username, when available |
|     ↳ `type` | string | Chat type: private, group, supergroup, or channel |
|   ↳ `date` | number | Unix timestamp when message was sent |
|   ↳ `text` | string | Text content of the sent message |

</ReferenceDetails>
