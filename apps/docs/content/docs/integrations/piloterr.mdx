[Piloterr](https://www.piloterr.com/) is a web scraping API with ready-made endpoints for search engines, marketplaces and company data, proxies and anti-bot handling included.

With the Piloterr block, you can:

- **Scrape pages**: fetch a page's HTML over HTTP, render a JavaScript page in a browser, or take a screenshot
- **Research websites**: detect the technologies a website runs
- **Search**: get Google organic results, and Amazon and eBay products with their prices and sellers
- **Enrich companies**: get LinkedIn and Crunchbase company profiles by page, name or website domain
- **Read listings**: get an eBay listing or a Zillow home with its price and details

Create an API key in the [Piloterr dashboard](https://app.piloterr.com/) and paste it into the block.

In Sim, the Piloterr block lets your agents monitor marketplace prices, enrich accounts and track search rankings.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Fetch or render any web page, take screenshots, detect a website's technologies, search Google, Amazon and eBay, and get structured LinkedIn and Crunchbase company profiles and Zillow properties, with proxies and anti-bot handling included.

## Actions

### Piloterr Fetch HTML

Fetch a public web page over fast HTTP, without running JavaScript, and get its HTML.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `url` | string | Yes | URL of the page \(e.g., "https://example.com") |
| `apiKey` | string | Yes | Piloterr API key |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `html` | string | HTML of the page |

</ReferenceDetails>

### Piloterr Render HTML

Render a JavaScript-heavy page in a headless browser and get the HTML after rendering.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `url` | string | Yes | URL of the page \(e.g., "https://example.com") |
| `waitInSeconds` | number | No | Seconds to wait after the page loads before reading the HTML \(defaults to 0\) |
| `blockAds` | boolean | No | Block ad requests while rendering |
| `apiKey` | string | Yes | Piloterr API key |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `html` | string | HTML of the page after rendering |

</ReferenceDetails>

### Piloterr Take Screenshot

Capture a public web page as a PNG, JPEG, WebP image or a PDF, by viewport, full page or CSS selector, and store it as a file.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `url` | string | Yes | URL of the page \(e.g., "https://example.com") |
| `format` | string | No | Output format: png, jpeg, webp or pdf \(defaults to "png"\) |
| `fullPage` | boolean | No | Capture the entire page instead of the visible viewport |
| `device` | string | No | Device to emulate \(e.g., "iphone_14_pro"\) |
| `selector` | string | No | CSS selector of one element to capture \(e.g., "#pricing"\) |
| `viewportWidth` | number | No | Width of the browser viewport in pixels \(defaults to 1280\) |
| `viewportHeight` | number | No | Height of the browser viewport in pixels \(defaults to 1024\) |
| `delay` | number | No | Seconds to wait before capturing \(defaults to 0\) |
| `removeCookieBanners` | boolean | No | Remove cookie banners before capturing |
| `removeAds` | boolean | No | Remove ads before capturing |
| `apiKey` | string | Yes | Piloterr API key |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `file` | file | Screenshot or PDF of the page, stored in the execution files |

</ReferenceDetails>

### Piloterr Google Search

Search Google and get organic results with their position, title, link and snippet, and the estimated total.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `query` | string | Yes | Search query \(e.g., "best electric cars"\) |
| `country` | string | No | Two-letter country code to search from \(e.g., "us"\) |
| `language` | string | No | Two-letter language code of the results \(e.g., "en"\) |
| `location` | string | No | City or region to search from \(e.g., "Paris, France"\) |
| `page` | number | No | Page of results, starting at 1 |
| `numResults` | number | No | Number of results per page \(e.g., 10\) |
| `apiKey` | string | Yes | Piloterr API key |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `results` | array | Organic results |
|   ↳ `position` | number | Position of the result on the page |
|   ↳ `title` | string | Title of the result |
|   ↳ `link` | string | URL of the result |
|   ↳ `domain` | string | Domain of the result |
|   ↳ `displayedLink` | string | Link as Google displays it |
|   ↳ `source` | string | Source or site name |
|   ↳ `snippet` | string | Snippet shown under the title |
| `totalResults` | number | Estimated total number of results |
| `hasNextPage` | boolean | Whether another page of results exists |

</ReferenceDetails>

### Piloterr Get eBay Listing

Get an eBay listing by item ID or URL, with its price, condition, availability, seller, shipping and item specifics.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `item` | string | Yes | eBay item ID or listing URL \(e.g., "257758922911"\) |
| `apiKey` | string | Yes | Piloterr API key |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `itemId` | string | eBay item ID |
| `title` | string | Title of the listing |
| `url` | string | URL of the listing |
| `price` | number | Price of the listing |
| `currency` | string | ISO 4217 code of the price |
| `priceDisplay` | string | Price as eBay displays it |
| `condition` | string | Condition of the item, such as New or Used |
| `conditionDescription` | string | Seller's description of the condition |
| `availability` | string | Availability, such as InStock or OutOfStock |
| `isBuyItNow` | boolean | Whether the listing can be bought now |
| `isBestOffer` | boolean | Whether the seller accepts best offers |
| `watchers` | number | Number of people watching the listing |
| `imageUrl` | string | URL of the main image |
| `seller` | object | Seller of the listing |
|   ↳ `name` | string | Name of the seller |
|   ↳ `feedback` | string | Feedback count of the seller |
|   ↳ `positiveFeedbackPercent` | number | Share of positive feedback, in percent |
| `shipping` | string | Shipping summary |
| `returns` | string | Returns policy summary |
| `specifications` | array | Item specifics |
|   ↳ `name` | string | Name of the specific |
|   ↳ `value` | string | Value of the specific |
| `paymentMethods` | array | Accepted payment methods |

</ReferenceDetails>
