## Usage Instructions

Connect an Oracle Fusion service-account credential to the Sales CRM REST API. Work with accounts, contacts, lead qualification and conversion, opportunities, tasks, appointments, call reports, revenue lines, and relationship teams. Lists return one bounded page. Fusion Service, Oracle B2C Service, triggers, and connectors are not included.
