{/* MANUAL-CONTENT-START:intro */}
[Gauge](https://withgauge.com) measures how brands appear in AI answers and which sources those answers cite.

With the Gauge block, you can:

- **Manage tracked questions**: Create topics, import prompts with a dry-run preview, update tracking types, and organize prompts with tags.
- **Investigate AI answers**: Read collected answers, brand mentions, citations, and search queries.
- **Report on visibility**: Discover available metrics and run reports across answers, citations, search queries, and AI traffic.

Create an organization API key in Gauge under **Settings → Integrations → API Keys**, then connect it as a saved Gauge account in Sim. **Read only** supports reads and report queries; **Read & write** also manages topics, prompts, and tags. Reconnect with a replacement key after rotation, expiry, or revocation. Temporary CLI login tokens are not supported.

Select an organization with Gauge Chat enabled and its category. Resource pickers also have a manual ID option in advanced mode. Answer pickers show the API's default recent window; use an answer ID directly for older answers. Follow `nextCursor` to retrieve additional result pages. Answer and citation filters default to the last seven days.

This integration covers all 27 Gauge Chat API operations. Gauge Agents uses a separate API and is outside this block's scope. See the [Gauge Chat API reference](https://docs.withgauge.com/chat/api-reference/overview) for the current limits and query catalog.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Manage organizations, categories, topics, tracked prompts, and tags; inspect brands, AI answers, citations, and search queries; and run visibility, share-of-voice, and AI-traffic reports with the Gauge Chat API.

## Report requirements

Answer lists support up to 100 results per page; other paginated lists support up to 200.

Read the query catalog before building reports. Visibility and share-of-voice metrics require a brand filter or brand grouping. Dataset filters and supported time granularities vary.
