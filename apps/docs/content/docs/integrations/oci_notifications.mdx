## Usage Instructions

Connect an OCI API-key service account to publish messages and manage topics, subscriptions, tags, compartments, and locks. Subscription and publish operations discover the topic endpoint using GetTopic and require ONS_TOPIC_READ in addition to their operation permissions. Use the recipient confirmation flow; pending subscriptions do not receive messages and Functions need no confirmation. Direct publication does not deliver SMS. Publish runs once, and acceptance is not delivery. Leave whole-block retries disabled because an ambiguous failure can still have published. Sim conservatively caps serialized publish requests at 64,000 UTF-8 bytes. No inbound trigger is provided.



## Actions

### OCI Notifications List Topics

List topics in one compartment, one page at a time.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `oauthCredential` | string | Yes | OCI API-key service account credential ID. |
| `region` | string | No | Optional OCI region; defaults to the saved credential region. |
| `compartmentId` | string | Yes | Compartment OCID. For subscriptions, use their current compartment, which may differ from the topic. |
| `id` | string | No | Optional exact topic OCID filter. |
| `name` | string | No | Topic name, unique across the tenancy when creating \(maximum 256 characters\). List filtering is exact. |
| `lifecycleState` | string | No | Filter topics by ACTIVE, CREATING, or DELETING. |
| `sortBy` | string | No | TIMECREATED \(default\) or LIFECYCLESTATE. |
| `sortOrder` | string | No | ASC or DESC. Time-created sorting defaults to DESC. |
| `limit` | number | No | Maximum results in this page: 1–50; Oracle defaults to 10. |
| `page` | string | No | Opaque nextPage token from the preceding list response. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `status` | number | HTTP status from Oracle. |
| `requestId` | string | Oracle request ID. |
| `nextPage` | string | Opaque next-page token. |
| `topics` | array | One page of topics. |
|   ↳ `freeformTags` | object | Freeform string tags. |
|   ↳ `definedTags` | object | Namespaced string tags. |
|   ↳ `topicId` | string | Topic OCID. |
|   ↳ `name` | string | Topic name. |
|   ↳ `compartmentId` | string | Topic compartment OCID. |
|   ↳ `lifecycleState` | string | ACTIVE, CREATING, or DELETING. |
|   ↳ `timeCreated` | string | RFC3339 creation time. |
|   ↳ `apiEndpoint` | string | Topic API endpoint; informational only. |
|   ↳ `description` | string | Topic description. |
|   ↳ `etag` | string | Resource ETag. |
|   ↳ `shortTopicId` | string | Short topic code for SMS. |
|   ↳ `systemTags` | object | Namespaced system tags. |
|   ↳ `locks` | array | Resource locks. |
|     ↳ `type` | string | FULL or DELETE. |
|     ↳ `compartmentId` | string | Lock compartment OCID. |
|     ↳ `message` | string | Lock reason. |
|     ↳ `relatedResourceId` | string | Locking resource OCID. |
|     ↳ `timeCreated` | string | RFC3339 lock creation time. |

### OCI Notifications Publish Message

Publish once to active subscriptions. Acceptance is not delivery; block retries can duplicate messages. Direct SMS is unsupported.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `oauthCredential` | string | Yes | OCI API-key service account credential ID. |
| `region` | string | No | Optional OCI region; defaults to the saved credential region. |
| `topicId` | string | Yes | Topic OCID. Subscription and publish endpoints are discovered with GetTopic; ONS_TOPIC_READ is required. |
| `body` | string | Yes | Message text. Sim caps the entire serialized request at 64,000 UTF-8 bytes. Publish runs once; keep block retries disabled to avoid duplicates. |
| `title` | string | No | Optional title, at most 255 characters. Used by email and PagerDuty; ignored by HTTPS, Slack, and SMS. |
