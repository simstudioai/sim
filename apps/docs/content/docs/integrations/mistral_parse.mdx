Use [Mistral's OCR API](https://mistral.ai/) to extract text and page structure from a PDF uploaded to Sim or passed in as a file from a previous block. The current parser returns page Markdown, image metadata, the model, and usage information. **Specific Pages** accepts zero-based indices such as `0,1,2`; leave it empty to process all pages. The block offers Markdown, plain-text, and JSON format values, but its current result uses the structured page output documented below. Turn on **Extract Images** to get the images Mistral finds in the document (figures, logos, photos) as files on the `images` output, up to 100 per parse; each page's image entry carries a `file_name` matching its file. **Max Images** and **Min Image Size** (advanced) narrow what is extracted. **Tables** keeps tables inline in the page Markdown by default, or returns them separately as Markdown or HTML in each page's `tables` list.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Extract text, tables, and images from an uploaded PDF or a file from a previous block. Images come back as files an agent can pass on.

## Actions

### Mistral PDF Parser

Parse PDF documents using Mistral OCR API

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `file` | file | Yes | Normalized UserFile from file upload or file reference |
| `resultType` | string | No | Legacy parser output format \(markdown, text, or json; default markdown\). Versions 2 and 3 return structured OCR pages regardless of this value. |
| `includeImageBase64` | boolean | No | Extract the images in the document \(figures, logos, photos\) as files on the images output |
| `pages` | array | No | Specific pages to process \(array of page numbers, starting from 0\) |
| `imageLimit` | number | No | Maximum number of images to extract \(at most 100\) |
| `imageMinSize` | number | No | Minimum height and width of images to extract from the PDF |
| `tableFormat` | string | No | Return tables separately on each page as markdown or html instead of inline in the page markdown |
| `apiKey` | string | Yes | Mistral API key \(MISTRAL_API_KEY\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `pages` | array | Array of page objects from Mistral OCR |
|   ↳ `index` | number | Page index \(zero-based\) |
|   ↳ `markdown` | string | Extracted markdown content |
|   ↳ `images` | array | Images extracted from this page with bounding boxes |
|     ↳ `id` | string | Image identifier \(e.g., img-0.jpeg\) |
|     ↳ `top_left_x` | number | Top-left X coordinate in pixels |
|     ↳ `top_left_y` | number | Top-left Y coordinate in pixels |
|     ↳ `bottom_right_x` | number | Bottom-right X coordinate in pixels |
|     ↳ `bottom_right_y` | number | Bottom-right Y coordinate in pixels |
|     ↳ `file_name` | string | Name of this image in the images output; present only when image extraction is on |
|   ↳ `dimensions` | object | Page dimensions |
|     ↳ `dpi` | number | Dots per inch |
|     ↳ `height` | number | Page height in pixels |
|     ↳ `width` | number | Page width in pixels |
|   ↳ `tables` | array | Separate table objects \(\{ id, content, format \}\), referenced from the markdown via placeholders like \[tbl-0.html\]. Populated only when tableFormat is markdown or html; otherwise tables stay inline in the markdown and this list is empty |
|   ↳ `hyperlinks` | array | Array of URL strings detected in the page |
|   ↳ `header` | string | Page header content. Mistral returns it only when extract_header is true \(it defaults to false\); Sim never sets it, so this is not returned |
|   ↳ `footer` | string | Page footer content. Mistral returns it only when extract_footer is true \(it defaults to false\); Sim never sets it, so this is not returned |
| `model` | string | Mistral OCR model identifier \(e.g., mistral-ocr-latest\) |
| `usage_info` | object | Usage and processing statistics |
|   ↳ `pages_processed` | number | Total number of pages processed |
|   ↳ `doc_size_bytes` | number | Document file size in bytes |
| `document_annotation` | string | Structured annotation data as JSON string \(when applicable\) |
| `images` | file[] | Images extracted from the document, named page-&lt;index&gt;-&lt;image id&gt; with the extension of the detected image type; empty unless image extraction is on |

</ReferenceDetails>
