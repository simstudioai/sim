{/* MANUAL-CONTENT-START:intro */}
[Oracle Fusion Cloud Financials](https://www.oracle.com/erp/financials/) manages enterprise accounting, receivables, payables, and employee expenses.

With the Oracle Fusion Financials block, you can:

- **Review payables**: Read invoices, invoice lines, and payments with their amounts and statuses.
- **Manage receivables**: Create and update invoices, approve eligible invoices, inspect lines and installments, create credit memos, and create and apply receipts.
- **Submit expenses**: Create and update expense reports and expense lines, then submit reports and inspect Oracle's validation result.
- **Report on accounting**: Read ledgers, journal batches, and ledger balances with bounded pagination.

Select **Add account** in the credential field and enter your Fusion Applications URL and integration user's username and password. Sim saves this as a reusable credential. Use an Oracle-assigned Fusion Applications origin, not the Oracle Cloud Infrastructure console or an EPM URL. Your integration user needs the Oracle roles and business-unit access required by each operation. No shared OAuth application is required.

Use IDs returned by list operations in later steps. Preserve decimal identifiers as strings, and use the returned opaque keys for payables invoices and expense resources. Receipt application takes the installment's `InstallmentId` as `appliedPaymentScheduleId`. Provide an explicit `amountApplied` for a partial application; omitting it asks Oracle to apply the full open transaction balance.

Each list returns one page, with `hasMore`, `count`, and `offset`. Advance the offset by the returned count when another page is needed. Lists are capped at 100 records per call. Actions report success only when Oracle returns the documented successful business result; submitting an expense report does not imply approval or payment.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Connect your Oracle Fusion Applications integration user through a reusable saved credential. Read payables invoices and payments; create and update receivables invoices, read their lines and installments, create credit memos, and create and apply receipts. Create, update, and submit expense reports and their expense lines. Read ledgers, journal batches, and ledger balances. Lists return one bounded page at a time. Oracle roles, business-unit access, and business validation still apply.

### Oracle Fusion Financials Apply Receivables Receipt

Apply a standard receipt to a Receivables invoice installment. An omitted amount applies the full open transaction balance.
