## Usage Instructions

Integrate Plane, the open-source project management tool, into workflows. Create, update, search, and triage work items; post comments and links; upload and download attachments; plan cycles and modules; and look up projects, states, labels, and members. Works with Plane Cloud and self-hosted instances.



## Actions

### Plane Create Work Item

Create a work item (issue) in a Plane project

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | Yes | Plane personal access token \(Profile Settings &gt; Personal Access Tokens\) |
| `workspaceSlug` | string | Yes | Workspace slug from the Plane URL \(e.g., "my-team" in app.plane.so/my-team/\) |
| `baseUrl` | string | No | Plane API host for self-hosted instances \(e.g., https://plane.example.com). Defaults to Plane Cloud \(https://api.plane.so) |
| `projectId` | string | Yes | Project ID \(UUID\) |
| `name` | string | Yes | Work item title |
| `description` | string | No | Work item description as HTML \(e.g., "&lt;p&gt;Steps to reproduce&lt;/p&gt;"\). Leave empty to keep the current description |
| `stateId` | string | No | State ID \(UUID\). Use List States to find state IDs |
| `priority` | string | No | Priority: urgent, high, medium, low, or none |
| `assigneeIds` | array | No | User IDs to assign \(UUIDs of active project members\). On update, replaces all assignees |
| `labelIds` | array | No | Label IDs to apply \(UUIDs from this project\). On update, replaces all labels |
| `parentId` | string | No | Parent work item ID \(UUID\) to nest this work item under |
| `startDate` | string | No | Start date in YYYY-MM-DD format |
| `targetDate` | string | No | Target \(due\) date in YYYY-MM-DD format |
| `estimatePointId` | string | No | Estimate point ID \(UUID\) |
| `typeId` | string | No | Work item type ID \(UUID\), for projects with work item types enabled |
| `externalId` | string | No | ID of this item in an external system. With externalSource, Plane rejects duplicates \(HTTP 409\) |
| `externalSource` | string | No | Name of the external system \(e.g., "github"\), used with externalId |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `workItem` | object | The created work item |
