{/* MANUAL-CONTENT-START:intro */}
[Dealport](https://dealport.com/) is the SMB knowledge layer for agents and teams: 28M+ US private companies, the commercial and multifamily buildings they own, and the human principals behind them, backed by primary public filings.

With the Dealport block, you can:

- **Size US SMB markets at $0.00**: run free market sizing counts across geography, NAICS industries, headcount, revenue, and regulatory attributes, and inspect up to 5 sample companies before opening paid Records
- **Search cited company and NYC building Records**: search 28M+ US private businesses or NYC multifamily and mixed-use buildings by borough, unit count, ACRIS loan maturity, mortgage holder, and distress signals
- **Inspect primary-filing evidence**: open complete company Records (by Dealport UUID) or NYC building Records (by 10-digit BBL) with filed, observed, and estimated facts, principals, identifiers, and source citations
- **Match external company rows and resolve verified owners**: match 1 to 250 company names and domains at $0.00 into Dealport Projects, and resolve verified human principals behind private companies, US LLCs, or property addresses with direct phones, emails, and professional profiles

Create a workspace API key in [Dealport](https://app.dealport.com/connect?tab=keys) under **Connect > API Keys** (it starts with `dp_live_`), grant the `read` scope for company, building, and Record operations and the `owners` scope for Find Owner, and add it from the block's **Dealport Account** field. New Dealport accounts start with a $5.00 free pay-as-you-go balance; 30-day workspace repeat reads cost $0.00.

In Sim, the Dealport block lets your agents size acquisition and sales territories, enrich inbound company tables with cited public-filing facts, monitor maturing building mortgages, and route verified principal contacts into your CRM.

## Use the block [#usage-instructions]

Size US private company markets at $0.00, search 28M+ US private companies and NYC commercial or multifamily buildings, open cited Records backed by primary public filings, match external company rows into Projects, and resolve verified human principals with direct phones, emails, and profiles.

## Actions

### Dealport Preview Companies

Run a free ($0.00) market sizing count across 28M+ US private companies and inspect up to 5 sample companies before opening paid Records.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `q` | string | No | Company name prefix filter \(e.g. "Buckeye Mechanical"\) |
| `state` | string | No | Two-letter US state code \(e.g. OH, TX, FL\) |
| `counties` | string | No | Comma-separated county names within state \(e.g. "Franklin,Cuyahoga"\) |
| `cities` | string | No | Comma-separated city names within state \(e.g. "Columbus,Cleveland"\) |
| `domain` | string | No | Company website host or registrable domain \(e.g. "acmemechanical.com"\) |
| `naics` | string | No | Comma-separated 2-to-6 digit NAICS codes \(e.g. "238220,332710"\) |
| `min_revenue` | number | No | Minimum annual revenue in USD |
| `max_revenue` | number | No | Maximum annual revenue in USD |
| `filed_revenue_only` | boolean | No | Restrict to primary filed revenue \(CMS cost reports or PPP filings\) |
| `min_employees` | number | No | Minimum employee headcount |
| `max_employees` | number | No | Maximum employee headcount |
| `size_unknown` | boolean | No | Include companies without reported size alongside sized matches |
| `independent` | boolean | No | Exclude SEC filers, nonprofits, government bodies, membership groups, and HOAs |
| `owner_businesses` | number | No | Minimum number of businesses associated with the same owner \(2 to 25\) |
| `medicare` | boolean | No | Require Medicare enrollment \(CMS certification number\) |
| `owner_operated` | boolean | No | Require owner-operated status in CMS filings |
| `owner_contact` | boolean | No | Require an owner phone or email already on file |
| `licensed` | boolean | No | Require an active state health license |
| `care_types` | string | No | Comma-separated NPI healthcare organization care types |
| `adviser` | boolean | No | Require SEC Form ADV investment adviser registration |
| `wealth_adviser` | boolean | No | Require individual wealth adviser profile \(no private funds, at least 20 clients\) |
| `online_store` | boolean | No | Require an indexed online storefront |
| `sells` | string | No | Comma-separated online store product categories |
| `store_words` | string | No | Comma-separated storefront full-text search terms |
| `min_reviews` | number | No | Minimum online store review count |
| `order` | string | No | Storefront sort order: reviews, products, or match |
| `markets` | json | No | Additional state and county markets as a JSON array of \{"state": "MI", "counties": \["Wayne", "Oakland"\]\} objects |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `matching_count` | number | Number of US private companies matching the buy-box filters |
| `matching_count_more` | boolean | Whether additional companies match beyond matching_count |
| `sample` | array | Up to 5 sample companies matching the filters |
|   ↳ `id` | string | Dealport company UUID |
|   ↳ `name` | string | Company name |
|   ↳ `city` | string | Company city |
|   ↳ `state` | string | Two-letter US state code |
|   ↳ `industry` | string | Primary industry label |
|   ↳ `employee_band` | string | Headcount range band |
|   ↳ `revenue_band` | string | Annual revenue range band |
|   ↳ `independent` | boolean | Whether the company is independent |
| `board_url` | string | Dealport web URL for inspecting the filtered market |
| `cost_usd` | number | USD charge for this request \($0.00 for market previews\) |
| `remaining_balance_usd` | number | Remaining workspace USD balance after the call |
