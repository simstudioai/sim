{/* MANUAL-CONTENT-START:intro */}
Use [Smartlead](https://www.smartlead.ai/) to manage outreach campaigns, multi-step sequences, sending mailboxes, and lead lists. Create or duplicate campaigns, configure schedules and settings, and change campaign status.

Lead actions import, list, export, find, update, categorize, pause, resume, complete, or unsubscribe leads. Campaign removal and global unsubscribe act on different scopes; choose the action that matches your intended change.

Read campaign, lead, and mailbox analytics, inbox replies, activity, and message history. Webhook actions register, update, list, or delete campaign webhooks so a workflow can process engagement events.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Create campaigns, write multi-step email sequences, import and categorize leads, pull campaign analytics, and register webhooks for engagement events.

### Smartlead Update Campaign Schedule

Sets the sending window, timezone, and throughput limits for a Smartlead campaign. A campaign cannot be started until a schedule exists.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `campaignId` | number | Yes | Smartlead campaign ID |
| `timezone` | string | Yes | IANA timezone for the sending window, e.g. America/Los_Angeles |
| `daysOfTheWeek` | array | Yes | Sending days as ISO weekday numbers, where 1 is Monday and 7 is Sunday |
| `startHour` | string | Yes | Sending window start in 24-hour HH:MM format, e.g. 09:00 |
| `endHour` | string | Yes | Sending window end in 24-hour HH:MM format, e.g. 17:00 |
| `minTimeBetweenEmails` | number | No | Minimum minutes to wait between emails |
| `maxNewLeadsPerDay` | number | No | Maximum new leads to contact per day |
| `scheduleStartTime` | string | No | ISO 8601 timestamp to begin sending, omit to start immediately |

No output fields are documented for this action.
