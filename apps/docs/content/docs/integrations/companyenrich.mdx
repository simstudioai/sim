{/* MANUAL-CONTENT-START:intro */}
[CompanyEnrich](https://companyenrich.com/) provides company and people data. This block includes twelve native operations: domain enrichment, company search, lookalikes, people search, email lookup, workforce, properties enrichment, batch enrichment, company and person retrieval by ID, and company/search-similarity counts.

Obtain an API key from the [CompanyEnrich dashboard](https://app.companyenrich.com/) and enter it in **API Key** without the `Bearer` prefix. The default **Enrich Company** operation accepts a domain such as `example.com`; a missing company returns HTTP 404. Company IDs are UUIDs. Enter person IDs as decimal strings to avoid rounding large identifiers.

**Search Query** performs literal company name/domain matching; **Semantic Query** accepts a natural-language company description. Use **Filters (JSON)** for full documented structured filters. Explicit inputs override the same keys in Filters. **Domains (JSON Array)** accepts one to ten lookalike seeds and takes precedence over the legacy **Company Domain** input. Batch enrichment accepts one to fifty domains. Properties enrichment requires at least one name or social property. Workforce requires exactly one company domain or UUID.

Search operations return one page per execution. **Page** defaults to 1 and **Page Size** to 10, with a maximum of 100; page times page size cannot exceed 10,000. Additional pages can consume credits. Enrichment costs 1 credit per call, search costs 1 per result (1 minimum), and similar-company discovery costs 5 per result (5 minimum). Optional **Expand (JSON Array)** supports `["workforce"]` on documented company operations or `["education"]` on people operations. Workforce expansion can spend additional credits. **Wait for Enrichment** is offered only on supported operations.

**Advanced Request** exposes 42 fixed, documented API operations, including previews, counts, cursor scrolls, bulk/export jobs, job status/listing, education, taxonomy and geographic lookups. Select **API Operation**, then provide its documented Body, Query Parameters and Path Parameters. Each execution makes exactly one request: no retries, automatic pagination, job polling or result-URL downloads. Paged requests default to page 1 and page size 10. Export creation requires an explicit count of 1–50,000; bulk jobs require explicit domains/items. Email operations marked beta require **Allow Beta Email Operations**. Saved-list administration and account `/me` responses are excluded. Returned job/result URLs are available for a later caller-controlled step.

The `data` output preserves the complete API JSON, including count zero, arrays, nested fields and metadata. Existing enrichment/search/lookalike outputs remain available: nullable scalar defaults and empty technology arrays retain their previous behavior, while company records now also retain extra provider fields. Similar-company results retain the convenience `scores` output. Use `data` when exact null values or the original response shape matter.

See the official [API reference](https://docs.companyenrich.com/reference) for each operation's fields, credit costs, account requirements and beta status. Provider errors report HTTP status without exposing response bodies or credentials. This contribution was validated with mocked responses; live authenticated execution has not been verified.

## Use the block [#usage-instructions]

Enrich companies, search companies and people, look up profiles, retrieve workforce data, and count matches. Advanced Request exposes 42 documented data and job operations. Data requests can consume credits; each execution makes one request.

## Actions

### CompanyEnrich Enrich Company

Enrich Company with CompanyEnrich. One request per execution; data requests can consume credits.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | Yes | CompanyEnrich API key without the Bearer prefix |
| `domain` | string | Yes | Company domain. For lookalikes, domains takes precedence over this legacy single seed. |
| `expand` | json | No | Expansion array: \["workforce"\] for companies \(can spend extra credits\) or \["education"\] for people. |
| `waitForEnrichment` | boolean | No | Wait for enrichment on supported company endpoints. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `company` | object | Company profile, including all provider fields. |
|   ↳ `id` | string | Company UUID |
|   ↳ `name` | string | Company name |
|   ↳ `domain` | string | Primary company domain |
|   ↳ `website` | string | Company website URL |
|   ↳ `description` | string | Company description |
|   ↳ `industry` | string | Primary industry |
|   ↳ `employees` | string | Employee count range |
|   ↳ `revenue` | string | Annual revenue range in USD |
|   ↳ `founded_year` | number | Year founded |
|   ↳ `technologies` | array | Technologies used |
| `data` | json | Complete unmodified company profile, preserving nulls and future fields. |

</ReferenceDetails>
