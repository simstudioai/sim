{/* MANUAL-CONTENT-START:intro */}
Use [Fivetran](https://www.fivetran.com/) to manage connections and monitor data syncs.

- List, read, create, update, pause, resume, or delete connections; inspect connector setup fields; and generate Connect Card links for source owners.
- Start syncs, re-sync connections or selected tables, run setup tests, reload schemas, and change which schemas and tables are synced.
- Read sync history, per-stage data volumes, warnings, schema configuration, and connection states.
- Create or inspect groups and destinations, test destinations, and list, run, or cancel transformations.
- Read account details, users, service accounts, and supported connector types.

## Authentication

In Fivetran, open your user menu and choose **API Key → Generate API key**. Under the block's **Fivetran Account** field, choose **Add API key** and enter the key and secret. Sim validates them, stores them encrypted as a reusable credential, and populates the Connection, Group, and Destination pickers. The key acts with its owner's Fivetran permissions.

## Webhook lifecycle

Triggers take the API key and secret directly. When you deploy the workflow, Sim registers an account-level or group-level webhook and generates its signing secret. Sim verifies incoming deliveries against that secret. Remove the trigger and redeploy to delete its webhook.

Triggers cover sync start/end, connection success/failure/change, table re-sync, and transformation start/success/failure events.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

List, create, update, pause, resume, and delete connections, trigger syncs and historical re-syncs, read sync history, warnings, and schema configs, enable or disable schemas and tables, run setup tests, generate Connect Card links, look up connector setup fields, create and inspect groups and destinations, run and cancel transformations, review users, and react to sync, connection, and transformation webhooks.
