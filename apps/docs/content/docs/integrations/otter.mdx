[Otter.ai](https://otter.ai/) is an AI meeting assistant that records, transcribes, and summarizes conversations.

With the Otter block, you can:

- **Read conversations**: List conversations and read each one's summary, action items, insights, outline, and transcript
- **Get recordings**: Get audio download links and import recordings for transcription
- **Browse your workspace**: List channels and their members, read workspace details, and list conversations across the workspace

To connect, enter an API key from an Otter Enterprise workspace. The Otter triggers can also start a workflow when a conversation finishes processing or is shared.

In Sim, the Otter block lets your agents act on your meetings: send action items to your task tracker, post summaries to Slack, or save transcripts to a knowledge base.
{/* MANUAL-CONTENT-END */}


## Usage Instructions

Integrate Otter.ai into your workflow to list and read meeting conversations with their summaries, action items, insights, outlines, and transcripts, get audio download links, import recordings, and browse channels and workspace details. Otter can also trigger workflows when a conversation finishes processing or is shared. Requires an Otter Enterprise workspace.



## Actions

### Otter List Conversations

List Otter conversations for the authenticated user, most recent first, optionally including shared conversations or filtering by channel.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | Yes | Otter API key |
| `includeShared` | boolean | No | Include conversations shared with the user \(default false\). Automatically true when a channel ID is provided. |
| `channelId` | string | No | Only return conversations in this channel. Overrides includeShared. |
| `limit` | number | No | Number of conversations per page \(1-100\) |
| `cursor` | string | No | Pagination cursor \(nextCursor from a previous response\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `conversations` | array | Conversations, most recent first |
|   ↳ `id` | string | Conversation ID |
|   ↳ `title` | string | Conversation title |
|   ↳ `url` | string | URL to view the conversation in Otter |
|   ↳ `owner` | object | Conversation owner |
|     ↳ `id` | string | User ID |
|     ↳ `name` | string | Full name |
|     ↳ `firstName` | string | First name |
|     ↳ `lastName` | string | Last name |
|     ↳ `email` | string | Email address |
|   ↳ `createdAt` | string | When the conversation was created |
|   ↳ `processStatus` | object | Processing status of generated data \(e.g., "finished"\); a field is null when not yet available |
|     ↳ `abstractSummary` | string | Summary status |
|     ↳ `actionItem` | string | Action item status |
|     ↳ `outline` | string | Outline status |
|   ↳ `calendarGuests` | array | Guests invited to the associated calendar event |
|     ↳ `name` | string | Guest name |
|     ↳ `email` | string | Guest email |
|     ↳ `permission` | string | Guest permission \(present in webhook payloads\) |
|   ↳ `sharedEmails` | array | Users or email addresses the conversation is shared with |
|     ↳ `email` | string | Shared email address |
|     ↳ `user` | object | Otter user for the email, if any |
|       ↳ `id` | string | User ID |
|       ↳ `name` | string | Full name |
|       ↳ `firstName` | string | First name |
|       ↳ `lastName` | string | Last name |
|       ↳ `email` | string | Email address |

|     ↳ `channel` | object | The channel |
|       ↳ `id` | string | Channel ID |
|       ↳ `name` | string | Channel name |
|       ↳ `memberCount` | number | Number of channel members |

|         ↳ `id` | string | User ID |

## Triggers

A **Trigger** is a block that starts a workflow when an event happens in this service.

|   ↳ `name` | string | Full name |

|   ↳ `lastName` | string | Last name |
