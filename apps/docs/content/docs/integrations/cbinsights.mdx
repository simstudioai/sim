{/* MANUAL-CONTENT-START:intro */}
[CB Insights](https://www.cbinsights.com/) provides company, investor, funding, cap-table, exit, relationship, and leadership data. Use its Mosaic Score, Commercial Maturity, and Exit Probability operations to retrieve scores, supporting signals, and history. Exit Probability includes a comparable-company mean and ratio. Cap-table history includes issuance and conversion prices, liquidation preferences, participation rights, and anti-dilution terms.

## Credentials and access

Obtain a client ID and secret from your CB Insights Customer Success Manager. Sim exchanges them for a short-lived bearer token automatically. Most data operations consume credits; access depends on your license for Firmographics, Financial Transactions, Business Relationships, Management and Board, Outlook, or Scouting Reports. Check your entitlements before building a workflow around a dataset.

## Working with company data

Use **Look Up Organizations** to match names or websites to CB Insights IDs before requesting paid data. The lookup is described as credit-free by the integration's endpoint contract; confirm current credit terms with CB Insights. Multi-organization **List** operations accept up to 100 organizations per call.

**Get Strategy Map** groups connected companies by category and includes their partnerships, investments, and acquisitions. **Get Scouting Report** generates company analysis, **Ask ChatCBI** answers questions with sources, and **Retrieve Context** supplies structured records for another model.

When `incompleteRoundType` identifies a pending round, all exit probabilities are suppressed to zero; a rumored round suppresses only the matching exit type. These zeroes indicate suppression rather than low predicted probability. Multi-organization responses can omit organizations with no data; compare returned IDs with your input before processing the result.

The streaming endpoints `chatcbichunked` and `scoutingreportstream` are not exposed. Use the non-streaming operations for a complete response. A Scouting Report can take several minutes to generate.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Look up companies, retrieve firmographic and transaction data, map business relationships, read leadership records and score history, and generate Scouting Reports or ChatCBI answers. Supply client credentials; dataset access and credit use depend on your CB Insights license.

## Actions

### CB Insights Look Up Organizations

Resolve company names or websites to CB Insights organization IDs. The integration contract describes lookup as credit-free; confirm current credit terms with CB Insights before requesting paid datasets.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `clientId` | string | Yes | CB Insights API client ID, exchanged for a bearer token before each call |
| `clientSecret` | string | Yes | CB Insights API client secret, exchanged for a bearer token before each call |
| `names` | json | No | Organization names to look up, e.g. \["CB Insights"\] |
| `urls` | json | No | Organization websites to look up, e.g. \["cbinsights.com"\] |
| `profileUrl` | string | No | A CB Insights profile URL to resolve. Mutually exclusive with names and urls — the API rejects a request that sets both. |
| `limit` | number | No | Rows to return in a single response, 1-100 |
| `nextPageToken` | string | No | Continuation token from a previous response; omit for the first page |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `orgs` | json | Matched organizations as \[\{orgId, name, description, aliases, urls\}\] |
| `nextPageToken` | string | Token for the next page, or null when there are no more results |
| `totalHits` | number | Total number of matching records |
| `totalHitsRelation` | string | Whether totalHits is exact \('eq'\) or a floor \('gte', used above 10,000\) |

</ReferenceDetails>
