{/* MANUAL-CONTENT-START:intro */}
Use [Linkup](https://linkup.so) to search the web from a workflow or an agent's tool set. Choose the supported search depth and output type for your query; results can include source URLs for downstream citation.

Supply your Linkup API key and query in the block. When using it as an agent tool, the agent decides when to call it based on its instructions.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Search the web with a Linkup API key, query, supported search depth, and output type.

## Actions

### Linkup Search

Search the web for information using Linkup

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `q` | string | Yes | The search query \(e.g., "latest AI research papers 2024"\) |
| `depth` | string | Yes | Search depth: "flash" \(lowest latency\), "fast" \(one-shot retrieval\), "standard" \(single agentic pass\), or "deep" \(multi-step, most thorough\) |
| `outputType` | string | Yes | Output format: "sourcedAnswer" for AI-generated answer with citations, "searchResults" for raw results |
| `apiKey` | string | Yes | Enter your Linkup API key |
| `includeImages` | boolean | No | Whether to include images in search results |
| `fromDate` | string | No | Start date for filtering results \(YYYY-MM-DD format\) |
| `toDate` | string | No | End date for filtering results \(YYYY-MM-DD format\) |
| `excludeDomains` | string | No | Comma-separated list of domain names to exclude from search results |
| `includeDomains` | string | No | Comma-separated list of domain names to restrict search results to |
| `includeInlineCitations` | boolean | No | Add inline citations to answers \(only applies when outputType is "sourcedAnswer"\) |
| `includeSources` | boolean | No | Include sources in response |
| `maxResults` | number | No | Maximum number of results to return \(at least 1\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `answer` | string | The sourced answer to the search query \(Answer output type\) |
| `sources` | array | Sources used to compile the answer \(Answer output type\) |
|   ↳ `name` | string | Title of the source |
|   ↳ `url` | string | URL of the source |
|   ↳ `snippet` | string | Text extracted from the source |
|   ↳ `favicon` | string | Favicon URL |
|   ↳ `publishedAt` | string | Publication date |
| `results` | array | Ranked text and image results \(Search output type\) |
|   ↳ `type` | string | Result type: text or image |
|   ↳ `name` | string | Title of the result |
|   ↳ `url` | string | URL of the result |
|   ↳ `content` | string | Extracted text content \(text results\) |
|   ↳ `favicon` | string | Favicon URL |
|   ↳ `publishedAt` | string | Publication date |

</ReferenceDetails>
