{/* MANUAL-CONTENT-START:intro */}
Use [Jupyter](https://jupyter.org/) to manage files, notebooks, kernels, and sessions on a self-hosted Jupyter server.

- List, read, create, upload, rename, copy, or delete files, notebooks, and directories.
- List, start, stop, restart, or interrupt kernels.
- List, create, or delete sessions that bind a notebook path to a kernel.

These operations manage notebook content and runtime lifecycle. Starting a kernel or creating a session does not itself execute notebook cells. Deleting a session also shuts down its associated kernel; save work first. See [Jupyter’s REST API](https://jupyter-server.readthedocs.io/en/latest/developers/rest-api.html#delete--api-sessions-session).
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Browse, read, create, upload, rename, copy, and delete files and notebooks; start, stop, restart, and interrupt kernels; and manage sessions that bind notebooks to kernels.

## Actions

### Jupyter List Contents

List files, notebooks, and subdirectories at a path on a Jupyter server

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `serverUrl` | string | Yes | Base URL of the Jupyter server \(e.g. http://localhost:8888) |
| `token` | string | Yes | Jupyter server authentication token |
| `path` | string | No | Directory path to list, relative to the server root. Leave blank for root. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `items` | array | Directory entries at the requested path |
|   ↳ `name` | string | Entry name |
|   ↳ `path` | string | Entry path relative to server root |
|   ↳ `type` | string | directory, file, or notebook |
|   ↳ `writable` | boolean | Whether the entry is writable |
|   ↳ `created` | string | Creation timestamp |
|   ↳ `lastModified` | string | Last modified timestamp |
|   ↳ `size` | number | Size in bytes |
|   ↳ `mimetype` | string | MIME type \(files only\) |
|   ↳ `format` | string | json, text, or base64 |
| `path` | string | The listed directory path |

</ReferenceDetails>
