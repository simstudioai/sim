{/* MANUAL-CONTENT-START:intro */}
Use [Databricks](https://www.databricks.com/) to execute parameterized SQL, manage jobs and runs, control compute clusters and SQL warehouses, and work with Genie spaces. Connect with a personal access token and your Databricks workspace host URL.

SQL operations return inline JSON rows, including SQL nulls. If a statement is still running, poll **Get Statement**. Follow `nextChunkIndex` with **Get Statement Chunk** to retrieve additional rows, or use **Cancel Statement** to stop execution. Configure `rowLimit` and `byteLimit` for predictable result sizes; external-link and Arrow/CSV downloads are outside these SQL operations.

Create, update, reset, or delete jobs; run saved jobs or submit one-time workloads. **Get Run** exposes task run IDs, resolved task values, repair history, and pagination. Use a task run ID with **Get Run Output**, and **Repair Run** to rerun failed tasks. Most job requests use Jobs API 2.2; existing offset pagination and notebook parameter overrides retain Jobs 2.1 compatibility. List operations return one page: pass `nextPageToken` back as `pageToken` to continue.

Cluster operations support creating, configuring, starting, restarting, resizing, terminating, and permanently deleting compute. Warehouse operations support configuration, scaling, starting, stopping, and deletion. Nested settings use Databricks API field names in JSON inputs, while dedicated inputs use the names listed below.

Genie operations create and update spaces, answer natural-language questions, manage conversation history, and retrieve generated SQL, results, and charts. Reuse the conversation ID for follow-ups. Use a space's `etag` when updating it to avoid overwriting concurrent changes. Agent mode supports research reports and response cancellation; it must be enabled in your workspace.

## Use the block [#usage-instructions]

Execute parameterized SQL and retrieve result chunks, create and manage jobs, submit and repair runs, manage compute clusters and SQL warehouses, and create or update Genie spaces. Ask Genie questions or run agent research, inspect conversations, and retrieve query results and charts. Connect with a personal access token and workspace host URL.

## Actions

### Databricks Execute SQL

Execute a SQL statement against a Databricks SQL warehouse and return results inline. Supports parameterized queries and Unity Catalog.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `host` | string | Yes | Databricks workspace host \(e.g., dbc-abc123.cloud.databricks.com\) |
| `apiKey` | string | Yes | Databricks Personal Access Token |
| `warehouseId` | string | Yes | The ID of the SQL warehouse to execute against |
| `statement` | string | Yes | The SQL statement to execute \(max 16 MiB\) |
| `catalog` | string | No | Unity Catalog name \(equivalent to USE CATALOG\) |
| `schema` | string | No | Schema name \(equivalent to USE SCHEMA\) |
| `rowLimit` | number | No | Maximum number of rows to return |
| `sqlParameters` | json | No | Named parameters as \[\{name, value, type\}\]; null or omitted value represents SQL NULL |
| `byteLimit` | number | No | Maximum result size in bytes; truncation is reported in the output |
| `onWaitTimeout` | string | No | CONTINUE \(default\) or CANCEL execution when the wait timeout expires |
| `waitTimeout` | string | No | How long to wait for results \(e.g., "50s"\). Range: "0s" or "5s" to "50s". Default: "50s" |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `totalChunks` | number | Number of result chunks |
| `chunkIndex` | number | Index of this result chunk |
| `rowOffset` | number | Starting row offset of this chunk |
| `rowCount` | number | Number of rows in this chunk |
| `nextChunkIndex` | number | Next chunk to retrieve with Get Statement Chunk; null on the final chunk |
| `nextChunkInternalLink` | string | Workspace-relative path to the next result chunk |
| `columns` | array | Column schema of the query result |
|   ↳ `name` | string | Column name |
|   ↳ `position` | number | Column position \(0-based\) |
|   ↳ `typeName` | string | Column type \(STRING, INT, LONG, DOUBLE, BOOLEAN, TIMESTAMP, DATE, DECIMAL, etc.\) |
| `data` | array | Result rows as a 2D array; each non-null value is a string and null values stay null |
| `totalRows` | number | Total number of rows in the result |
| `truncated` | boolean | Whether the result set was truncated |
| `statementId` | string | SQL statement ID of the query |
| `status` | string | Statement status \(PENDING, RUNNING, SUCCEEDED, FAILED, CANCELED, CLOSED\) |

</ReferenceDetails>
