## Usage Instructions

Use a reusable OCI API-key service account to invoke functions synchronously or in detached mode, discover applications and functions, and manage their configuration and existing container image references. Detached acknowledgements do not contain completed results. Image builds, registry uploads, and source deployment are outside this integration.



## Actions

### OCI Functions Invoke

Invoke an OCI function synchronously, start a detached invocation, or dry-run without executing. Payloads and results are limited to 6 MB. Detached HTTP 202 acknowledges processing and is not a completed result. One provider invocation attempt per tool execution; keep block retries disabled to avoid replay. A lost response can follow successful execution; cancellation ends the wait, not the Oracle execution.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `oauthCredential` | string | Yes | Reusable OCI API-key service-account credential ID |
| `region` | string | No | OCI region identifier; omit to use the credential region |
| `functionId` | string | Yes | Function OCID; endpoint is discovered through an authenticated management read |
| `invocationType` | string | No | sync \(default\) or detached |
| `dryRun` | boolean | No | Validate invocation without executing the function \(default false\) |
| `intent` | string | No | Optional fn-intent: httprequest or cloudevent |
| `payloadType` | string | No | json \(default\), text, or file |
| `payload` | json | No | JSON value, or a string for text mode; omit for an empty body. JSON false, 0, null, and empty strings are preserved. |
| `file` | file | No | One uploaded UserFile for file mode; access is checked before download |
| `contentType` | string | No | Content type override; otherwise inferred from payload mode or uploaded file |
| `outputFormat` | string | No | auto \(default\) returns JSON/text or a file for binary data; file returns an execution file, except an empty body returns an empty string |
| `timeoutMs` | number | No | Client wait timeout in milliseconds, 1–300000 \(default 300000\); execution cancellation can end it earlier |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `status` | number | HTTP status returned by Oracle |
| `opcRequestId` | string | Oracle request identifier, when returned |
| `functionId` | string | Invoked function OCID |
| `invocationType` | string | Requested invocation mode: sync or detached |
| `dryRun` | boolean | Whether this was a dry-run request |
| `accepted` | boolean | True for HTTP 202 acknowledgement; no completed result is available |
| `contentType` | string | Result content type, when a result is returned |
| `result` | json | Synchronous JSON value or text; empty response body becomes an empty string. Absent for acknowledgements, dry runs, or non-empty file output. |
| `file` | file | Binary or explicitly requested file result, stored as an execution file |
