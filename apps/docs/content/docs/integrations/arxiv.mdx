[arXiv](https://arxiv.org/) hosts research papers. Search by keyword, author, title, or category, retrieve a paper’s metadata, or list papers by an author. This integration does not require an API key or OAuth connection.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Search arXiv papers, retrieve paper metadata, or list an author’s papers. No API key or OAuth connection is required.

## Actions

### ArXiv Search

Search for academic papers on ArXiv by keywords, authors, titles, or other fields.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `searchQuery` | string | Yes | The search query to execute |
| `searchField` | string | No | Field to search in: all, ti \(title\), au \(author\), abs \(abstract\), co \(comment\), jr \(journal\), cat \(category\), rn \(report number\) |
| `maxResults` | number | No | Maximum number of results to return \(default: 10, max: 2000\) |
| `sortBy` | string | No | Sort by: relevance, lastUpdatedDate, submittedDate \(default: relevance\) |
| `sortOrder` | string | No | Sort order: ascending, descending \(default: descending\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `papers` | array | Array of papers matching the search query |
|   ↳ `authors` | array |  |
|   ↳ `categories` | array |  |
|   ↳ `comment` | string |  |
|   ↳ `journalRef` | string |  |
|   ↳ `doi` | string |  |
| `totalResults` | number | Total number of results found for the search query |
| `query` | string | The search query that was executed |

</ReferenceDetails>

### ArXiv Get Author Papers

Search for papers by a specific author on ArXiv.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `authorName` | string | Yes | Author name to search for |
| `maxResults` | number | No | Maximum number of results to return \(default: 10, max: 2000\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `authorPapers` | array | Array of papers authored by the specified author |
|   ↳ `authors` | array |  |
|   ↳ `categories` | array |  |
|   ↳ `comment` | string |  |
|   ↳ `journalRef` | string |  |
|   ↳ `doi` | string |  |
| `totalResults` | number | Total number of papers found for the author |
| `authorName` | string | The author name that was searched |

</ReferenceDetails>
