[Amazon EC2](https://aws.amazon.com/ec2/) provides resizable virtual servers in AWS. The EC2 API also covers the VPC networking around them (subnets, route tables, NAT and internet gateways, security groups, network interfaces, and Elastic IP addresses) and the EBS volumes and snapshots that back them.

With the Amazon EC2 block, you can:

- **Inventory and control instances**: List instances with their state, type, IPs, and tags, read status checks and scheduled maintenance events, and start, stop, reboot, or terminate instances
- **Manage Elastic IPs**: List Elastic IP addresses and what they are attached to, allocate new addresses, associate them with an instance or network interface, disassociate them, and release them
- **Inspect VPC networking**: Read VPCs, subnets, route tables with their routes and associations, NAT gateways with their public IPs, internet gateways, network ACLs, VPC endpoints, VPC peering connections, security groups with their inbound and outbound rules, and network interfaces
- **Control security group ingress**: Add an inbound rule, or revoke rules by rule ID or by protocol, ports, and source
- **Work with EBS**: List volumes and snapshots, create a snapshot of a volume, and delete volumes and snapshots
- **Tag resources**: Add, overwrite, or remove tags on any EC2 resource ID
- **Explore the account**: List AMIs, key pairs, Regions, and Availability Zones

## Credentials and permissions

The block authenticates with an AWS access key ID and secret access key and runs in the region you set. Grant the IAM principal only the EC2 actions the operations you use require. Each operation maps to the IAM action of the same name, for example `ec2:DescribeAddresses`, `ec2:DescribeNatGateways`, and `ec2:DescribeRouteTables` for a read-only egress audit, or `ec2:StopInstances` and `ec2:StartInstances` for scheduling.

List operations accept EC2 filters such as `[{"Name": "vpc-id", "Values": ["vpc-0abc123"]}]`. Without IDs they return up to 100 results per page, with a `nextToken` for the next page.

In Sim, the Amazon EC2 block lets your agents map which public IPs your subnets egress through, find idle Elastic IPs and unattached volumes, audit and close open security group rules, back up volumes and prune old snapshots on a schedule, and stop non-production instances outside working hours.

## Use the block [#usage-instructions]

Integrate Amazon EC2 into workflows. Describe and control instances, manage Elastic IP addresses, inspect VPCs, subnets, route tables, NAT and internet gateways, security groups, and network interfaces, add and revoke security group ingress rules, inspect network ACLs, VPC endpoints, and peering connections, work with EBS volumes and snapshots, list AMIs and key pairs, and tag resources. Requires an AWS access key with the matching ec2:* IAM permissions.

### EC2 Describe Instances

List EC2 instances with their state, type, networking, and tags

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `awsRegion` | string | Yes | AWS region \(e.g., us-east-1\) |
| `awsAccessKeyId` | string | Yes | AWS access key ID |
| `awsSecretAccessKey` | string | Yes | AWS secret access key |
| `instanceIds` | string | No | Comma-separated instance IDs \(e.g., i-0abc123,i-0def456\). Leave empty to list all |
| `filters` | json | No | EC2 filters as a JSON array, e.g. \[\{"Name":"instance-state-name","Values":\["running"\]\}\] |

| `nextToken` | string | No | Pagination token from a previous response |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `nextToken` | string | Pagination token for the next page, or null when there are no more results |
| `instances` | array | EC2 instances |
|   ↳ `tags` | json | Resource tags as key/value pairs |
|   ↳ `instanceId` | string | Instance ID |
|   ↳ `instanceType` | string | Instance type \(e.g., t3.micro\) |
|   ↳ `state` | string | Instance state \(pending, running, stopping, stopped, shutting-down, terminated\) |
|   ↳ `stateReason` | string | Reason for the most recent state transition |
|   ↳ `launchTime` | string | Launch time \(ISO 8601\) |
|   ↳ `availabilityZone` | string | Availability Zone |
|   ↳ `vpcId` | string | VPC ID |
|   ↳ `subnetId` | string | Subnet ID |
|   ↳ `privateIpAddress` | string | Primary private IPv4 address |
|   ↳ `publicIpAddress` | string | Public IPv4 address |
|   ↳ `privateDnsName` | string | Private DNS name |
|   ↳ `publicDnsName` | string | Public DNS name |
|   ↳ `imageId` | string | AMI ID used to launch the instance |
|   ↳ `keyName` | string | Key pair name |
|   ↳ `platformDetails` | string | Platform details \(e.g., Linux/UNIX, Windows\) |
|   ↳ `architecture` | string | CPU architecture |
|   ↳ `iamInstanceProfileArn` | string | ARN of the attached IAM instance profile |
|   ↳ `securityGroups` | array | Attached security groups |
|     ↳ `groupId` | string | Security group ID |
|     ↳ `groupName` | string | Security group name |
