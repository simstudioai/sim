Use [Twilio SMS](https://www.twilio.com/en-us/sms) to send a text message from a workflow. Configure the Twilio credentials, sending number, recipient, and message body documented below.

Connect Twilio once as a Twilio credential with your Account SID and either the account's Auth Token or an [API key](https://www.twilio.com/docs/iam/api-keys). Enter an API key as its SID and secret joined by a colon (`SKxxx:secret`). A Standard or Main key works; a restricted key needs read access to phone numbers. Workflows built with the earlier Twilio block keep the Account SID and Auth Token they entered in the block.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Send SMS messages.

## Actions

### Twilio Send SMS

Send text messages to single or multiple recipients using the Twilio API.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `phoneNumbers` | string | Yes | Phone numbers to send the message to in E.164 format \(e.g., +15551234567\), separated by newlines |
| `message` | string | Yes | Message to send |
| `fromNumber` | string | Yes | Twilio phone number to send the message from in E.164 format \(e.g., +15551234567\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `success` | boolean | SMS send success status |
| `messageId` | string | Unique Twilio message identifier \(SID\) |
| `status` | string | Message delivery status from Twilio |
| `fromNumber` | string | Phone number message was sent from |
| `toNumber` | string | Phone number message was sent to |

</ReferenceDetails>
