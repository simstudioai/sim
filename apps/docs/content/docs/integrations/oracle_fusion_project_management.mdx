## Usage Instructions

Connect an Oracle Fusion service-account credential to manage project delivery and project financial workflows. Read visible plans and manage authorized tasks, milestones, deliverables, team members, and labor assignments. Work with project costs, budgets, and project-contract invoices without administering the Financials, HCM, or Procurement products. API contracts target Oracle 26C and the fixed FSCM REST version. Management privileges, enabled modules, financial plan types, status rules, and tenant configuration determine availability. No live tenant validation is implied.



## Actions

### Oracle Fusion Project Management List Projects

List projects in Oracle Fusion Cloud Project Management. Returns one bounded page, not an automatically drained collection.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `oauthCredential` | string | Yes | Reusable Oracle Fusion service-account credential |
| `q` | string | No | Optional oracle q filter using attributes documented for this collection |
| `orderBy` | string | No | Documented sort attributes for this collection, for example TaskId:asc for tasks; use a stable order when paging |
| `limit` | number | No | One page of 1–1000 items; default 100 |
| `offset` | number | No | Zero-based offset for this page; use nextOffset to continue |
| `totalResults` | boolean | No | Include oracle’s estimated total row count |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `items` | array | This page of project records |
| `count` | number | Items in this page |
| `hasMore` | boolean | Whether Oracle reports another page |
| `limit` | number | Page size used by Oracle |
| `offset` | number | Offset used for this page |
| `nextOffset` | number | Offset to request next when hasMore is true |
| `totalResults` | number | Estimated total when requested |
