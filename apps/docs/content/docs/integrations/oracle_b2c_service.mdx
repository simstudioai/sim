## Usage Instructions

Create, retrieve, update, delete, filter, sort, and page through Oracle B2C Service incidents, contacts, organizations, and Classic Answers using the Connect REST API.



## Actions

### Oracle B2C Service List Incidents

Return one bounded page of Oracle B2C Service incident summaries.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `siteUrl` | string | Yes | Oracle B2C Service REST Server origin, for example https://example.custhelp.com |
| `username` | string | Yes | Oracle B2C Service staff account username |
| `password` | string | Yes | Oracle B2C Service staff account password |
| `applicationContext` | string | No | OSvC-CREST-Application-Context value used for Oracle resource-pool reporting \(defaults to Sim; maximum 40 characters\) |
| `q` | string | No | Oracle collection filter expression |
| `orderBy` | string | No | Oracle collection sort expression, for example updatedTime:desc |
| `limit` | number | No | Maximum items in this single page \(1-1000; defaults to 100\) |
| `offset` | number | No | Zero-based number of items to skip |
| `includeTotalResults` | boolean | No | Ask Oracle to include totalResults for the filtered collection |
| `pageUrl` | string | No | Same-origin nextPageUrl or previousPageUrl from an earlier call. Mutually exclusive with q, orderBy, limit, offset, and includeTotalResults. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `resource` | json | Created or retrieved Oracle resource |
| `items` | array | One bounded Oracle collection page |
| `count` | number | Items in the returned page |
| `hasMore` | boolean | Whether Oracle reports another page |
| `totalResults` | number | Total matching resources when requested |
| `nextPageUrl` | string | URL for the next page |
| `previousPageUrl` | string | URL for the previous page |
| `id` | string | Updated or deleted resource ID |
| `updated` | boolean | Whether the resource was updated |
| `deleted` | boolean | Whether the resource was deleted |
| `incident` | json | Incident that received a response |
| `responseSent` | boolean | Whether the response was sent |
