## Use the block [#usage-instructions]

{/* MANUAL-CONTENT-START:usage */}
## Set up the Wiza API key [#wiza-api-key-setup]

1. Sign in to your [Wiza account](https://app.wiza.co/).
2. Open **Settings → API** and create a key, or copy an existing one.
3. Paste it into the block's **Wiza API Key** field.

The key is used for each operation. Wiza's [rate-limit guide](https://help.wiza.co/en/articles/12325950-wiza-api-rate-limits) currently lists Individual Reveal at 15 requests per second. Limits vary by endpoint; reduce request frequency after a `429` response.

## Individual Reveal

Select **Individual Reveal** and supply a LinkedIn URL, a name plus company/domain, or an email. The operation starts enrichment and polls at two-second intervals for up to 60 attempts. It returns contact data, `status`, and `is_complete` when a terminal result arrives. No separate polling block or callback URL is required.

An incomplete reveal after that polling window fails the block. Three consecutive failed HTTP polling responses also fail it. Wiza may continue processing an already-started reveal; inspect the reveal in Wiza before submitting it again.

## Enrichment levels and credits [#enrichment-levels-and-credits]

| Level | Requested data | Provider credit use |
| --- | --- | --- |
| `none` | Profile and company data; no contact details | 1 credit for a matched LinkedIn profile |
| `partial` | Emails, with work/personal acceptance controls | 2 credits when a valid email is returned |
| `phone` | Phone numbers | 5 credits when a phone is returned |
| `full` | Emails and phones | Applicable email and phone charges |

Check `wiza_get_credits` before large batches and inspect the response's `credits` object. Wiza documents deductions when data is found; see its [API guide](https://help.wiza.co/en/articles/14115896-wiza-api-everything-you-need-to-know) for current credit rules. Sim-provided API keys have their own metering; distinguish that charge from the provider balance on a key you supply.

## Actions

### Wiza Prospect Search

Search Wiza's database of prospects using person, company, and financial filters

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | Yes | Wiza API key |
| `size` | number | No | Number of sample profiles to return \(0-30, default 0\) |
| `filters` | object | No | Full filters object \(overrides individual filter params if provided\) |
| `first_name` | array | No | Exact first names to match \(e.g., \["John", "Jane"\]\) |
| `last_name` | array | No | Exact last names to match |
| `job_title` | array | No | Job titles to include/exclude \(e.g., \[\{"v":"CEO","s":"i"\},\{"v":"CTO","s":"e"\}\]\) |
| `job_title_level` | array | No | Seniority levels \(e.g., \["cxo", "director", "manager"\]\) |
| `job_role` | array | No | Job role categories \(e.g., \["sales", "engineering", "marketing"\]\) |
| `job_sub_role` | array | No | Detailed role categories \(e.g., \["software", "product"\]\) |
| `location` | array | No | Person's location filters \(city/state/country with include/exclude\) |
| `skill` | array | No | Professional skills \(e.g., \["python", "marketing"\]\) |
| `school` | array | No | Educational institutions |
| `major` | array | No | Field of study |
| `linkedin_slug` | array | No | LinkedIn profile slugs |
| `job_company` | array | No | Current company filters \(include/exclude\) |
| `past_company` | array | No | Past company filters |
| `company_location` | array | No | Company HQ location filters |
| `company_industry` | array | No | Company industry filters \(include/exclude\) |
| `company_size` | array | No | Company headcount brackets \(e.g., \["1-10", "11-50", "51-200"\]\) |
| `company_type` | array | No | Company type \(e.g., \["private", "public", "educational"\]\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `total` | number | Total number of matching prospects |
| `profiles` | array | Sample profiles matching the filter criteria |

</ReferenceDetails>

### Wiza Individual Reveal

Reveal a contact by LinkedIn URL, name plus company/domain, or email. Starts the reveal and polls at two-second intervals for up to 60 attempts, failing if it remains incomplete. Wiza charges 2 credits for a valid email, 5 for a phone, or 1 for a matched profile-only reveal.

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | Yes | Wiza API key |

| `profile_url` | string | No | LinkedIn profile URL \(e.g., https://linkedin.com/in/johndoe) |
| `full_name` | string | No | Full name \(used with company or domain\) |
| `company` | string | No | Company name \(used with full_name\) |
| `domain` | string | No | Company domain \(used with full_name\) |
| `email` | string | No | Email address \(use alone or with other identifiers\) |
