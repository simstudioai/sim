## Usage Instructions

Automate Cloud PCM Management Ledger applications using the epm/rest/v1 API family. This is distinct from Enterprise Profitability and Cost Management (EPCM). Use a provisioned PCM environment under an eligible EPM Enterprise or legacy PCM subscription. Most operations require Service Administrator or Power User; creating an application requires Service Administrator. Report and query-export submissions accept all application roles, but task polling requires Service Administrator or Power User. File operations and file selectors require Service Administrator or an application role with Migrations - Administer. Upload inputs to profitinbox and download reports from profitoutbox. Downloads require repository paths of at most 255 UTF-8 bytes; use short output filenames. Submission and waiting are separate; retain processName and inspect the Job Library after ambiguous failures. Application, POV, model view, rule, and query names are manual inputs. Template export and undocumented nested rule-balancing fields are not exposed.
