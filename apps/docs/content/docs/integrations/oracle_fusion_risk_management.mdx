## Usage Instructions

Connect an Oracle Fusion integration-user credential to maintain Financial Reporting Compliance processes, risks, controls, issue remediation fields, assessment results, supporting relationships, and test procedures. Investigate Advanced Controls incidents, simulate proposed access, and administer Risk Management assignment groups. Each list returns one bounded page. Identifiers and resource numeric values are returned as decimal strings; pagination values remain numbers. Supply integer IDs as quoted decimal strings in mutation JSON. Group security assignments secure the group itself. Assessment updates do not certify or approve assessments, simulations do not grant access or create incidents, and changing control metadata does not execute controls. Requires licensed and enabled Oracle product features, REST privileges, and object-level access. No risk updates, issue creation, approval/provisioning workflows, control execution, test-plan creation, binary attachments, tenant-specific flexfield writes, or platform administration are included.

## Prerequisites and API contract

Create or select a reusable Oracle Fusion integration-user connection in the block, containing the application URL, username, and password. The existing Fusion connection supplies Basic authentication over HTTPS. The integration user needs the relevant Financial Reporting Compliance or Advanced Controls REST privileges, the feature's duty roles, and access to the individual records. Assignment-group security permissions apply to the group itself; membership does not automatically assign every compliance record.

Financial Reporting Compliance and Advanced Controls capabilities depend on the customer's Oracle subscriptions and enabled tenant features. Assigning privileges can affect license consumption even when those privileges are unused. Customer entitlement, feature configuration, and live tenant behavior have not been verified. Consult Oracle's [REST quick start](https://docs.oracle.com/en/cloud/saas/risk-management-and-compliance/26c/farkm/Quick_Start.html), [26C API reference](https://docs.oracle.com/en/cloud/saas/risk-management-and-compliance/26c/farkm/index.html), and [licensing advisory](https://docs.oracle.com/en/cloud/saas/risk-management-and-compliance/26c/farsr/advisory-note-on-licensing-impact.html).

### Supported behavior

The block provides processes, risks, controls, issues, three assessment-result families, documented comments and perspectives, process-risk relationships, assertions, action items, test plans and steps, and plan activities. Advanced Controls operations cover control configuration, incidents and their comments and transaction attributes, open incidents, job status, and proposed-access simulation with separate status and results retrieval. Assignment operations cover groups, members, group security assignments, eligible users, securable types, and role types. Each resource exposes only its documented operations.

Mutation JSON is restricted to each action's documented fields. Omitted fields remain unchanged; only documented nullable fields accept null. Pass numeric identifiers as quoted decimal strings. Preserve opaque `key` values from list results together with their parent identifiers. A successful assertion update can return a new key. Creating a group member or group security assignment first resolves the selected group's business identifier. Child records without a picker use manual identifiers from their corresponding list actions.

Each list retrieves at most 100 records and returns pagination metadata. Supply `nextOffset` to fetch another page. Simulation submission returns a request identifier, not completed results or access grants. Read status separately before requesting results. Updating assessment responses does not certify them; updating issue remediation fields does not approve or close issues; editing control configuration does not run controls.

### Deliberate exclusions

Oracle explicitly marks [risk updates](https://docs.oracle.com/en/cloud/saas/risk-management-and-compliance/26c/farkm/op-frcrisks-riskid-patch.html) and [issue creation](https://docs.oracle.com/en/cloud/saas/risk-management-and-compliance/26c/farkm/op-frcissues-post.html) unsupported. The block also excludes control execution because the published `RunMode` descriptions conflict, test-plan creation because a supported source for the required creation identifier is unverified, and role-check actions because the complete no-violations response contract is unclear. Mass incident edits and tenant-specific flexfields are omitted because their complete request contracts are unverified.

There are no assessment-certification or approval actions, Advanced Access Requests provisioning workflows, synchronization or datasource administration, binary enclosures, triggers, or generic request tools. OCI Cloud Guard, Security Zones, and IAM are separate products and are outside this integration.
