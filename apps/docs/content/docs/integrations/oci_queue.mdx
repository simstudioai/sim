## Usage Instructions

Connect an OCI API-key service account to manage queues and exchange bounded message batches. Data endpoints are discovered through authenticated GetQueue. Processing uses current receipts for acknowledgement and visibility changes. Receive is one bounded poll; schedule it in a workflow when needed and leave automatic retries disabled for message operations. Queue management returns asynchronous work request IDs. OCI IAM must permit the selected control or message operation and QUEUE_READ for endpoint discovery.

### OCI Queue List Queues

List one page of OCI queues with exact-name and lifecycle filters.

| --------- | ---- | -------- | ----------- |
| `oauthCredential` | string | Yes | OCI API-key service account credential ID. |

| `compartmentId` | string | No | Compartment OCID. Required to create a queue; optional for API listing. |
| `displayName` | string | No | Queue display name \(1–255 characters\); list filtering matches exactly. |
| `id` | string | No | Optional exact queue OCID filter. |
| `lifecycleState` | string | No | CREATING, UPDATING, ACTIVE, DELETING, DELETED, FAILED, or INACTIVE. |

| `sortOrder` | string | No | ASC or DESC. |
| `limit` | number | No | Maximum items in this page \(1–1000\); receiving accepts only 1–20. |
| `page` | string | No | Opaque nextPage token from a previous response. |

| Parameter | Type | Description |
| --------- | ---- | ----------- |

|   ↳ `systemTags` | object | System tags. |

### OCI Queue Create Queue

Request queue creation and return its work request. An explicit retry token enables at most two tokenized attempts.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `oauthCredential` | string | Yes | OCI API-key service account credential ID. |
| `region` | string | No | Optional OCI region; defaults to the saved credential region. |
| `compartmentId` | string | Yes | Compartment OCID. Required to create a queue; optional for API listing. |
| `displayName` | string | Yes | Queue display name \(1–255 characters\); list filtering matches exactly. |
| `retentionInSeconds` | number | No | Message retention: 10–604800 seconds. Creation only. |
| `visibilityInSeconds` | number | No | Visibility duration: 0–43200 seconds; queue defaults require at least 1. Zero releases a received message. |
| `timeoutInSeconds` | number | No | Long-poll duration: 0–30 seconds. Zero does not wait. |
| `deadLetterQueueDeliveryCount` | number | No | Delivery attempts before dead-lettering: 1–20; 0 disables dead-lettering. |
| `channelConsumptionLimit` | number | No | Channel consumption limit percentage: 1–100. |
| `customEncryptionKeyId` | string | No | Optional KMS key OCID. An empty string removes it during update. |
| `freeformTags` | json | No | Object mapping freeform tag names to string values. |
| `definedTags` | json | No | Object mapping tag namespaces to their tag-name/value objects. |
| `retryToken` | string | No | Optional Oracle creation retry token \(1–64 characters\). Enables two tokenized attempts within the deadline. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `status` | number | HTTP status from Oracle. |
| `requestId` | string | Oracle request ID. |
| `workRequestId` | string | Accepted asynchronous work request OCID. |
