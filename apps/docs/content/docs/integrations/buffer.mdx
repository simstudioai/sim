[Buffer](https://buffer.com/) is a social media management platform that lets teams draft, schedule, and publish content across their connected social channels from a single queue. Each channel — Instagram, LinkedIn, X, Facebook, TikTok, and more — is connected once in Buffer, and posts are published on the schedule you define.

With the Buffer integration in Sim, you can:

- **Publish and schedule posts**: Create a post for a channel and add it to the queue, share it immediately, schedule it for a specific time, or save it as a draft
- **Attach media**: Include images, videos, or documents and configure network-specific metadata
- **Manage existing posts**: Edit, retrieve, list, and delete posts
- **Browse channels**: List connected channels or retrieve a channel's complete settings and posting schedule
- **Check publishing limits and performance**: Read daily posting limits and aggregate published-post metrics
- **Capture ideas**: Create ideas and list ideas and idea groups from the Buffer content pipeline
- **Read account details**: Retrieve the authenticated Buffer account

To connect, create an API key in Buffer under **Settings → API**, then enter it in the block's **API Key** field. Sim sends the key as a Bearer token to Buffer's GraphQL API. The key can access all organizations and channels available to your Buffer account.

Enable the permissions needed by your workflow: `account:read`, `posts:read`, `posts:write`, `ideas:read`, `ideas:write`, and `insights:read`. This integration includes 13 operations for posts, channels, ideas, account details, and reporting. Preview operations are excluded.

Advanced JSON inputs expose the full nested contracts for assets, network metadata, idea content, filters, and sorting. Choose either the single-file media controls or the assets array. Each asset contains exactly one image, video, or document. Listing operations return one page with complete cursor information; use `after` to continue. Sim limits each page to 100 items and structured input arrays to 1,000 items.

When editing a post, select **Keep current schedule** in **Share Mode** and **Keep current publishing method** in **Scheduling Type** to update content without rescheduling. Existing workflows retain their configured share mode; select **Keep current schedule** when their edits should preserve the post's schedule.

Use **Clear Caption** to remove an existing caption, or an empty assets/tag ID array to clear those values. Omitting them preserves the existing values. The live API accepts date comparators and tag comparators for post filters; the older documented `startDate`, `endDate`, and `tagIds` filter fields are unavailable. Link attachments belong in network metadata.

In Sim, the Buffer integration enables your agents to turn generated content into scheduled social posts without manual copy-paste. An agent can draft copy, look up the right channel, attach a generated image, and queue the post — or review the existing queue and clean up posts that are no longer relevant.

## Usage Instructions

Integrate Buffer into your workflow. Create, schedule, edit, and delete posts across connected social channels (Instagram, LinkedIn, X, Facebook, TikTok, and more), attach images or videos, browse channel settings, check daily limits and post metrics, and capture content ideas using the Buffer API.

### Buffer Get Posts

List posts in a Buffer organization, optionally filtered by channel and status (draft, needs_approval, scheduled, sending, sent, error)

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | Yes | Buffer API key |
| `organizationId` | string | Yes | Buffer organization ID \(find it with the Get Account operation\) |
| `channelIds` | string | No | Comma-separated channel IDs to filter by |
