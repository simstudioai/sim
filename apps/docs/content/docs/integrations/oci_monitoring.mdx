## Usage Instructions

Connect a reusable OCI API signing-key credential to discover metrics, run MQL queries, publish custom metrics, and manage alarms and maintenance suppressions. Reads and histories return one bounded page; queries expose explicit stream and datapoint budgets. Alarm destinations reference existing Notifications topics or Streaming streams. IAM policies must grant the selected operations in the alarm and metric compartments; creating and updating alarms also require metric-read access. Use the separate OCI Logging integration for logs.



## Actions

### OCI Monitoring List Metrics

Discover metric definitions and namespaces

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `oauthCredential` | string | Yes | Reusable OCI API signing-key credential. |
| `region` | string | No | OCI region override; omit to use the credential region. |
| `compartmentId` | string | Yes | Compartment OCID. Subtree queries require the tenancy OCID and tenancy-level access. |
| `namespace` | string | No | Metric namespace, such as oci_computeagent. |
| `name` | string | No | Exact metric name to discover. |
| `resourceGroup` | string | No | Metric resource group; null matches metrics without a resource group. |
| `dimensionFilters` | json | No | JSON object of dimension names and exact string values. Metric discovery ignores this when groupBy is supplied. |
| `groupBy` | json | No | JSON array of namespace, name, or resourceGroup. When present, dimensionFilters is ignored. |
| `sortBy` | string | No | Sort field: NAMESPACE, NAME, or RESOURCEGROUP. |
| `sortOrder` | string | No | Sort direction: ASC or DESC. |
| `compartmentIdInSubtree` | boolean | No | Include child compartments; requires the tenancy OCID and tenancy-level permissions. |
| `limit` | number | No | Maximum results on this page: 1–1000; defaults to 100. |
| `page` | string | No | Opaque nextPage from the previous response. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `opcRequestId` | string | Oracle request ID |
| `metrics` | array | Discovered metric definitions; grouping can omit non-grouped fields |
| `nextPage` | string | Opaque token for the next page; null when complete |

### OCI Monitoring Query Metrics

Query and aggregate metric time series with MQL

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `oauthCredential` | string | Yes | Reusable OCI API signing-key credential. |
| `region` | string | No | OCI region override; omit to use the credential region. |
| `compartmentId` | string | Yes | Compartment OCID. Subtree queries require the tenancy OCID and tenancy-level access. |
| `namespace` | string | Yes | Metric namespace, such as oci_computeagent. |
| `query` | string | Yes | Oracle MQL expression, such as CpuUtilization\[1m\].mean\(\); alarm expressions also require a threshold or absence condition. |
| `resourceGroup` | string | No | Metric resource group; null matches metrics without a resource group. |
| `startTime` | string | No | Inclusive RFC3339 query start. Oracle defaults to three hours before the request. |
| `endTime` | string | No | Exclusive RFC3339 query end. Oracle defaults to request time. |
| `resolution` | string | No | Aggregation window spacing, no greater than the MQL interval. Queries accept 1m–60m, 1h–24h, or 1d; alarms accept only 1m. |
| `compartmentIdInSubtree` | boolean | No | Include child compartments; requires the tenancy OCID and tenancy-level permissions. |
| `maxStreams` | number | No | Maximum returned metric streams: defaults to 100, up to 2000. Excess results fail without truncation. |
| `maxDatapoints` | number | No | Maximum total returned datapoints: defaults to 10000, up to 100000. Excess results fail without truncation. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `opcRequestId` | string | Oracle request ID |
| `metricData` | array | Aggregated metric time series |
|   ↳ `name` | string | Metric name |
|   ↳ `namespace` | string | Metric namespace |
|   ↳ `resourceGroup` | string | Resource group |
|   ↳ `compartmentId` | string | Metric compartment OCID |
|   ↳ `dimensions` | json | Dimension names and string values |
|   ↳ `metadata` | json | Metric metadata such as unit |
|   ↳ `resolution` | string | Aggregation spacing |
|   ↳ `aggregatedDatapoints` | array | Aggregated datapoints |
|     ↳ `timestamp` | string | Datapoint timestamp \(RFC3339\) |
|     ↳ `value` | number | Aggregated value |

### OCI Monitoring Publish Metrics

| --------- | ---- | -------- | ----------- |

|   ↳ `metricData` | json | Metric record rejected by Oracle |
|     ↳ `name` | string | Metric name |
|     ↳ `namespace` | string | Metric namespace |
|     ↳ `resourceGroup` | string | Resource group |
|     ↳ `compartmentId` | string | Metric compartment OCID |
|     ↳ `dimensions` | json | Dimension names and string values |
|     ↳ `datapoints` | array | Submitted datapoints |
|       ↳ `timestamp` | string | Raw datapoint timestamp |

|     ↳ `metadata` | json | Metric metadata |

### OCI Monitoring Create Alarm

Create a metric alarm using existing notification destinations

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `oauthCredential` | string | Yes | Reusable OCI API signing-key credential. |
| `region` | string | No | OCI region override; omit to use the credential region. |
| `displayName` | string | Yes | Alarm or suppression display name; list operations use exact matching. |
| `compartmentId` | string | Yes | Compartment OCID. Subtree queries require the tenancy OCID and tenancy-level access. |
| `metricCompartmentId` | string | Yes | Compartment OCID containing the metrics evaluated by the alarm. |
| `namespace` | string | Yes | Metric namespace, such as oci_computeagent. |
| `query` | string | Yes | Oracle MQL expression, such as CpuUtilization\[1m\].mean\(\); alarm expressions also require a threshold or absence condition. |
| `severity` | string | Yes | Alarm severity: CRITICAL, ERROR, WARNING, or INFO. |
| `destinations` | json | Yes | JSON array of existing Notifications topic or Streaming stream OCIDs; at most one per destination service. |
| `isEnabled` | boolean | Yes | Whether the alarm evaluates its MQL condition. Omit on update to preserve the existing value. |
| `metricCompartmentIdInSubtree` | boolean | No | Evaluate metrics in child compartments; requires tenancy-level metric access. |
| `resourceGroup` | string | No | Metric resource group; null matches metrics without a resource group. |
| `resolution` | string | No | Aggregation window spacing, no greater than the MQL interval. Queries accept 1m–60m, 1h–24h, or 1d; alarms accept only 1m. |
| `pendingDuration` | string | No | ISO 8601 duration before firing, from PT1M to PT1H. |
| `body` | string | No | Alarm notification message body. |
| `isNotificationsPerMetricDimensionEnabled` | boolean | No | Send separate notifications per metric stream; required by Oracle for dimension-specific suppression. |
| `messageFormat` | string | No | Notification format: RAW, PRETTY_JSON, or ONS_OPTIMIZED. |
| `repeatNotificationDuration` | string | No | ISO 8601 interval for repeating notifications. |
| `suppression` | json | No | JSON object with timeSuppressFrom, timeSuppressUntil, and optional description. Use Remove Alarm Suppression to clear it. |
| `freeformTags` | json | No | JSON object of string tag names and values. |
| `definedTags` | json | No | JSON object of tag namespaces and values. |
| `overrides` | json | No | JSON array of up to two alarm trigger-rule overrides. |
| `ruleName` | string | No | Name of the base alarm rule. |
| `notificationVersion` | string | No | Oracle alarm notification version. |
| `notificationTitle` | string | No | Custom title for alarm notifications. |
| `evaluationSlackDuration` | string | No | ISO 8601 ingestion delay before evaluation, from PT3M to PT2H. |
| `alarmSummary` | string | No | Custom alarm summary. |
| `opcRetryToken` | string | No | Stable retry token for creation. Enables bounded tokenized retries; reuse it for the same logical creation. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `opcRequestId` | string | Oracle request ID |
| `alarm` | json | Alarm configuration |
| `etag` | string | Concurrency ETag |
