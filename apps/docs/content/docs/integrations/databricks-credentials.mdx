A Databricks connection holds a workspace host and how Sim authenticates to it. The Databricks block can select a saved connection instead of taking a host and token typed into the block.

<Callout type="info">
Blocks that already use a host and personal access token keep working exactly as they are. Selecting a saved connection is optional.
</Callout>

## Choose how Sim signs in

| Option | What Sim stores | When to use it |
| --- | --- | --- |
| **Service principal (keyless, via Sim OIDC)** | Nothing secret: the host and the service principal's application ID | Recommended. No secret to rotate or leak. |
| **Service principal OAuth secret** | The application ID and an OAuth secret | Machine-to-machine access where federation isn't set up. Sim exchanges the secret for a short-lived token on each run. |
| **Personal access token** | A personal access token | The same behavior as a token typed into the block, shared across blocks. |

Every option resolves on Sim's servers at run time; tokens never appear in block outputs, logs, or anything a model sees.

## Set up a keyless service principal [#keyless-service-principal]

<Steps>
  <Step>
    In Sim, add a **Databricks connection**, choose **Service principal (keyless, via Sim OIDC)**, and enter the workspace host and the service principal's **application ID**.
  </Step>
  <Step>
    A Databricks account admin runs the **Federation policy** command from the dialog with the service principal's numeric ID. The policy trusts Sim's issuer, the Sim audience, and this connection's subject only.
  </Step>
  <Step>
    Make sure the service principal can access the workspace and the resources your workflows use, then save. Sim verifies the connection by exchanging a token and reading the service principal's identity.
  </Step>
</Steps>

## Self-hosted deployments

Keyless connections need `WORKLOAD_IDENTITY_SIGNING_KEY` set and an issuer Databricks can reach over the public internet. See [AWS credentials](/integrations/aws-credentials#self-hosted-deployments) for the same settings.
