{/* MANUAL-CONTENT-START:intro */}
[Help Scout](https://www.helpscout.com/) is a customer support platform with shared inboxes, a help center, and live chat.

With the Help Scout block, you can:

- **Work the queue**: List and search conversations by inbox, folder, status, tag, assignee, or search query, and read conversations with their threads.
- **Respond to customers**: Open conversations, send replies or save them as drafts, and add internal notes.
- **Route and organize**: Change a conversation's status, assignee, inbox, subject, and tags, delete conversations, and run manual workflows.
- **Manage customers**: Search, read, create, and update customer profiles.
- **Look up your account**: List inboxes, folders, users, teams, tags, and workflows.
- **React to events**: Start workflows when conversations are created, replied to, assigned, tagged, moved, merged, or deleted, or when customers are created or updated.

Connect your Help Scout account through OAuth, or save your own Help Scout app as a credential: create an app under **Your Profile > My Apps** (a placeholder redirect URL is fine) and paste its App ID and App Secret. Either way, Sim acts with the permissions of the Help Scout user behind the connection, who needs the **Access API** permission.

For triggers, add the Webhooks app in Help Scout (**Settings > Workspace > Apps > Webhooks**), paste the trigger's webhook URL as the callback URL, and enter the same secret key in Help Scout and in the trigger. Sim verifies every delivery's `X-HelpScout-Signature`.

In Sim, the Help Scout block lets your agents triage new conversations, draft replies from your knowledge base, keep customer records current, and report on what your support team is handling.

## OAuth scopes [#oauth-scopes]

Sim requests no OAuth scopes for Help Scout. For a self-hosted deployment, register your own app with the provider using the settings below. See [Integrations and OAuth](/platform/self-hosting/integrations-oauth) for setup.

| Setting | Value |
| ------- | ----- |
| Redirect URI | `<NEXT_PUBLIC_APP_URL>/api/auth/oauth2/callback/helpscout` |
| Environment variables | `HELPSCOUT_CLIENT_ID`, `HELPSCOUT_CLIENT_SECRET` |

## Use the block [#usage-instructions]

Connect Help Scout to search and read conversations and their threads, open new conversations, reply to customers, add internal notes, change status, assignee, inbox, subject, and tags, and manage customers. List inboxes, folders, users, teams, tags, and workflows, and run manual workflows. Trigger workflows from Help Scout webhooks for conversation and customer events.

## Actions

### Help Scout List Conversations

List and search Help Scout conversations by inbox, folder, status, tag, assignee, or search query. Returns 25 conversations per page.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `mailboxId` | string | No | Inbox ID to filter by; comma-separate several IDs |
| `folderId` | string | No | Folder ID to filter by |
| `status` | string | No | active, open, pending, closed, spam, or all \(defaults to active\) |
| `tag` | string | No | Tag to filter by; comma-separate several tags |
| `assignedTo` | string | No | User ID of the assignee to filter by |
| `modifiedSince` | string | No | Only conversations modified after this time \(e.g. 2024-05-04T12:00:03Z\) |
| `number` | number | No | Conversation number to look up |
| `sortField` | string | No | createdAt, customerEmail, customerName, mailboxid, modifiedAt, number, score, status, subject, or waitingSince |
| `sortOrder` | string | No | asc or desc \(defaults to desc\) |
| `query` | string | No | Advanced search query, e.g. \(email:"jane@example.com" AND tag:"vip"\) |
| `page` | number | No | Page number to fetch, starting at 1 |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `conversations` | array | Conversations on this page |

### Help Scout Create Conversation

Create a Help Scout conversation in an inbox with a first customer message, reply, or note. A new customer is created when the email is not already known.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `subject` | string | Yes | Conversation subject |
| `mailboxId` | string | Yes | ID of the inbox to create the conversation in |
| `type` | string | No | email, chat, or phone \(defaults to email\) |
| `status` | string | No | active, pending, or closed \(defaults to active\) |
| `customerId` | string | No | Existing customer ID; takes precedence over the customer email |
| `customerEmail` | string | No | Customer email, used when no customer ID is given |
| `customerFirstName` | string | No | First name, used only when a new customer is created |
| `customerLastName` | string | No | Last name, used only when a new customer is created |
| `threadType` | string | No | customer \(a message from the customer\), reply \(a reply to the customer\), or note \(defaults to customer\) |
| `text` | string | Yes | Text of the first thread |
| `assignTo` | string | No | User or team ID to assign; omit to follow the inbox settings |
| `tags` | string | No | Comma-separated tags to add |
| `autoReply` | boolean | No | Send the inbox auto reply; only valid when threadType is customer |
| `userId` | string | No | ID of the user creating the conversation; defaults to the connected user |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `id` | number | ID of the new conversation |
| `webUrl` | string | Link to the new conversation in Help Scout |
