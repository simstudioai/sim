{/* MANUAL-CONTENT-START:intro */}
Use [Help Scout](https://www.helpscout.com/) to manage support conversations and customers, or start workflows from conversation and customer events.

## Connect Help Scout

Connect through OAuth, or save your own Help Scout app as a credential. For an app credential, open **Your Profile > My Apps**, create an app, and save its **App ID** and **App Secret** in Sim. The client-credentials flow does not use the redirect URL. The connected user needs **Access API** permission. See [Help Scout authentication](https://developer.helpscout.com/mailbox-api/overview/authentication/).

Triggers require an OAuth connection. Select the account and, optionally, an inbox, then deploy the workflow. Sim creates a webhook with a signing secret, validates each delivery's `X-HelpScout-Signature`, and removes the webhook when the workflow is undeployed.

To make past support history searchable, add Help Scout as a [knowledge base source](/knowledgebase/connectors). Sync conversations and threads from one inbox or all inboxes, with internal notes included only when selected.
{/* MANUAL-CONTENT-END */}

## OAuth scopes [#oauth-scopes]

Sim requests no OAuth scopes for Help Scout. For a self-hosted deployment, register your own app with the provider using the settings below. See [Integrations and OAuth](/platform/self-hosting/integrations-oauth) for setup.

| Setting | Value |
| ------- | ----- |
| Redirect URI | `<NEXT_PUBLIC_APP_URL>/api/auth/oauth2/callback/helpscout` |
| Environment variables | `HELPSCOUT_CLIENT_ID`, `HELPSCOUT_CLIENT_SECRET` |

## Use the block [#usage-instructions]

Connect Help Scout to search and read conversations and their threads, open new conversations, reply to customers, add internal notes and customer messages, change status, assignee, inbox, subject, customer, tags, and custom fields, and snooze conversations. Manage customers and their properties, look up organizations and saved replies, list inboxes, folders, users, teams, tags, and workflows, and run manual workflows. Trigger workflows from Help Scout webhooks for conversation and customer events.

### Help Scout Create Conversation

Create a Help Scout conversation in an inbox with a first customer message, reply, or note. A new customer is created when the email is not already known.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `subject` | string | Yes | Conversation subject |
| `mailboxId` | string | Yes | ID of the inbox to create the conversation in |
| `type` | string | No | email, chat, or phone \(defaults to email\) |
| `status` | string | No | active, pending, or closed \(defaults to active\) |
| `customerId` | string | No | Existing customer ID; takes precedence over the customer email |
| `customerEmail` | string | No | Customer email, used when no customer ID is given |
| `customerFirstName` | string | No | First name, used only when a new customer is created |
| `customerLastName` | string | No | Last name, used only when a new customer is created |
| `threadType` | string | No | customer \(a message from the customer\), reply \(a reply to the customer\), or note \(defaults to customer\) |
| `text` | string | Yes | Text of the first thread |
| `assignTo` | string | No | User or team ID to assign; omit to follow the inbox settings |
| `tags` | string | No | Comma-separated tags to add |
| `autoReply` | boolean | No | Send the inbox auto reply; only valid when threadType is customer |
| `userId` | string | No | ID of the user creating the conversation; defaults to the connected user |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `id` | number | ID of the new conversation |
| `webUrl` | string | Link to the new conversation in Help Scout |

</ReferenceDetails>
