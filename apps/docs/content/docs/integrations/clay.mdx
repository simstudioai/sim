{/* MANUAL-CONTENT-START:intro */}
[Clay](https://www.clay.com/) organizes and enriches data in tables. Use the Clay Populate action to send structured data from your Sim workflow to a Clay table through its webhook URL—for example, lead records or research results.
{/* MANUAL-CONTENT-END */}


## Use the block [#usage-instructions]

Send structured records to a Clay table through its webhook URL.

## Actions

### Clay Populate

Send structured JSON data to a Clay table webhook and return its response and HTTP metadata.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `webhookURL` | string | Yes | The webhook URL to populate |
| `data` | json | Yes | The data to populate |
| `authToken` | string | No | Optional auth token for Clay webhook authentication \(most webhooks do not require this\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `data` | json | Response data from Clay webhook |
| `metadata` | object | Webhook response metadata |
|   ↳ `status` | number | HTTP status code |
|   ↳ `statusText` | string | HTTP status text |
|   ↳ `headers` | object | Response headers from Clay |
|   ↳ `timestamp` | string | ISO timestamp recorded when the webhook response was processed |
|   ↳ `contentType` | string | Content type of the response |
