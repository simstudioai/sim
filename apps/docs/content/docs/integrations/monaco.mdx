{/* MANUAL-CONTENT-START:intro */}
[Monaco](https://www.monaco.com/) is an AI-native revenue platform that combines a CRM, a prospect database, outbound sequencing, and a meeting recorder in one system.

With the Monaco block, you can:

- **Manage CRM records**: list, read, create, update, upsert, and delete contacts and accounts, and manage opportunities with their pipeline stage, estimated value, linked contacts, and custom fields
- **Track work**: create and update tasks, including email tasks with a draft, and create or list tags for contacts, accounts, and opportunities
- **Read activity**: list meetings and read their AI summaries, next actions, and transcripts, and read a contact's or account's email and LinkedIn messages and full conversation threads
- **Run outreach**: build audiences from contact IDs or filters, enroll contacts or attach audiences to campaigns, and pause, resume, enqueue, stop, or exclude sequences
- **Discover your workspace**: list pipelines and users, and read the filterable and sortable field schemas for each record type

Create an API key in Monaco under **Settings > API Keys** (it starts with `mks_` and is shown once), then add it as a Monaco credential from the block's **Monaco Account** field. Enrolling contacts, attaching audiences to campaigns, and resuming or enqueuing sequences send real email and LinkedIn messages.

In Sim, the Monaco block lets your agents prepare account briefs before meetings, keep the pipeline clean, turn meeting outcomes into follow-up tasks, and launch outbound to a new segment.
{/* MANUAL-CONTENT-END */}

## Use the block [#usage-instructions]

Connect a Monaco API key to read and write contacts, accounts, and opportunities, manage tasks and tags, read meetings, transcripts, and email or LinkedIn conversations, and run outreach by building audiences, enrolling contacts in campaigns, and controlling sequences.

### Monaco Create Contact

Create a Monaco contact from an email or LinkedIn URL. Monaco enriches the contact and resolves or creates its account, which can take several seconds. A duplicate email or LinkedIn URL is rejected; use Upsert Contact to update a match instead.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `email` | string | No | Email address of the contact \(max 255 characters\). Either email or LinkedIn URL is required. |
| `linkedinUrl` | string | No | LinkedIn profile URL \(a linkedin.com/in/... URL\). Either email or LinkedIn URL is required; with only a LinkedIn URL, also pass an account ID or domain. |
| `firstName` | string | No | First name of the contact \(max 256 characters\) |
| `lastName` | string | No | Last name of the contact \(max 256 characters\) |
| `title` | string | No | Job title of the contact |
| `phoneNumber` | string | No | Phone number of the contact |
| `location` | string | No | Location of the contact \(max 256 characters\) |
| `accountId` | string | No | ID of the account to associate the contact with. Takes priority over domain, then the domain parsed from email, when resolving the account. |
| `domain` | string | No | Domain of the contact's company, used to resolve its account |
| `doNotContact` | boolean | No | Whether the contact has opted out of outreach |
| `notes` | string | No | Notes about the contact \(max 1,125,000 characters\) |
| `tags` | array | No | Tag IDs for the contact, as an array or comma-separated list. When the request matches an existing contact, replaces its existing tags. |
| `isInbound` | boolean | No | Whether the contact is an inbound lead. When true and the request creates a new contact, Monaco records it as a captured inbound lead. Ignored when the request matches an existing contact. Defaults to false. |
| `customFields` | json | No | Custom field values as a JSON object keyed by `custom_field_&lt;id&gt;` \(e.g. \{"custom_field_1a2b...": "economic_buyer"\}\). Use Get Field Schemas to find the keys. |

Create a Monaco audience, optionally seeded with contacts: either an explicit list of contact IDs, or a filters query over the contact field schemas (optionally narrowed by excluded IDs or a source audience). Audiences can be shared across campaigns.

<ReferenceDetails>

### Monaco Enroll Campaign Contacts

Enroll contacts in a Monaco campaign. This sends real outreach: enrolled contacts are placed on the campaign sequence, which sends real emails and LinkedIn messages. Monaco always creates a new audience with the given name, attaches it to the campaign, and adds the contacts to it. The campaign must be active or paused. Sequences are created asynchronously, so contacts already enrolled are deduplicated later and still count as successes.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `campaignId` | string | Yes | ID of the campaign to enroll contacts in; it must be active or paused |
| `audienceName` | string | Yes | Name for the new audience created to hold these contacts \(1 to 255 characters\); pick something short and relevant to the enrollment. Must be unique within the organization: a duplicate name is rejected, so vary it and retry. |
| `contactIds` | array | Yes | IDs of the contacts to enroll \(1 to 10,000\), as an array or comma-separated list |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `successCount` | number | Contacts added to the campaign's new audience |
| `failureCount` | number | Contacts that could not be added \(e.g. not found in the organization\) |
| `failureReasons` | array | Failure reasons with the number of contacts affected by each |
|   ↳ `code` | string | Failure reason code \(e.g. contact_has_active_sequence\) |
|   ↳ `description` | string | Human-readable description of the failure reason |
|   ↳ `count` | number | Number of contacts that hit this failure |

</ReferenceDetails>
