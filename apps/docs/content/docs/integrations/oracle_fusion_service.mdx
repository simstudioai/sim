## Usage Instructions

Connect a stored Oracle Fusion service account to the Sales and Fusion Service ADF REST API (crmRestApi, 11.13.18.05). Manage service requests, status transitions, queue assignment, contacts, and team memberships. Read customer accounts, contacts, agent resources, business units, messages, internal notes, and interaction references. Directory records remain read-only. This is not Oracle B2C Service and does not implement Fusion Sales workflows. Message/note writes, sending email, attachments, and knowledge endpoints are not supported.

### Oracle Fusion Service Create Service Request

#### Input

| Parameter | Type | Required | Description |

| `oauthCredential` | string | Yes | Stored Oracle Fusion service-account credential. |

| `contactPartyId` | string | No | Contact PartyId as an exact decimal string. |
| `severityCode` | string | No | Tenant severity code from ORA_SVC_SR_SEVERITY_CD. |
| `channelTypeCode` | string | No | Tenant channel code from ORA_SVC_CHANNEL_TYPE_CD. |
| `statusCode` | string | No | Tenant service request status LookupCode. Oracle enforces valid transitions. |
| `queueId` | string | No | QueueId as an exact decimal string. |
| `resourcePartyId` | string | No | Agent resource PartyId, not ResourceProfileId. Sent as AssigneeResourceId or child ObjectId. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `item` | object | Documented Oracle resource fields. |
