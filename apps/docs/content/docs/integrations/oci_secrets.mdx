## Usage Instructions

Manage Oracle Cloud Infrastructure secrets with a stored OCI API signing-key service account. Read metadata or deliberately retrieve secret content, manage versions and stages, create and update secrets, configure generation and cross-region replication, schedule or cancel deletion, and monitor rotation work requests. Discover existing vaults and encryption keys without granting this block key-management or cryptographic mutation capabilities. Oracle IAM separately controls secret metadata, secret versions, secret bundles, vaults and keys. Manual OCID inputs avoid discovery permissions; configure the compartment inputs in basic mode to use the pickers. Pending deletion blocks content retrieval, and permanent deletion cannot be reversed. Rotation and creation may still be in progress after acceptance.



## Actions

### OCI Secrets List Secrets

List secret metadata in a compartment without retrieving secret contents.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `oauthCredential` | string | Yes | Stored OCI API signing-key service account. |
| `region` | string | No | Optional OCI region override in the credential realm, such as us-ashburn-1. Defaults to the credential region. |
| `compartmentId` | string | Yes | Compartment OCID. For Move Secret, this is the destination compartment. |
| `name` | string | No | Exact secret name filter. |
| `vaultId` | string | No | Vault OCID. Key discovery additionally requires read access to this vault. |
| `lifecycleState` | string | No | Secret lifecycle state: CREATING, ACTIVE, UPDATING, DELETING, DELETED, SCHEDULING_DELETION, PENDING_DELETION, CANCELLING_DELETION or FAILED. |
| `limit` | number | No | Maximum items in one page, from 1 to 1000. Returns a nextPage token when more results remain. |
| `page` | string | No | Opaque nextPage token from the previous response. |
| `sortBy` | string | No | Sort secrets by NAME or TIMECREATED. |
| `sortOrder` | string | No | Sort direction: ASC or DESC. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `status` | number | Oracle HTTP response status; 202 means accepted, not completed |
| `opcRequestId` | string | Oracle request ID |
| `nextPage` | string | Opaque continuation token for the next page |
| `secrets` | array | Secret metadata in this page |

### OCI Secrets Create Secret

Create a secret with supplied base64 content or automatic generation. Requires secret creation, vault use and encryption key permissions.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `oauthCredential` | string | Yes | Stored OCI API signing-key service account. |
| `region` | string | No | Optional OCI region override in the credential realm, such as us-ashburn-1. Defaults to the credential region. |
| `compartmentId` | string | Yes | Compartment OCID. For Move Secret, this is the destination compartment. |
| `secretName` | string | Yes | Secret name, unique within its vault; up to 255 characters. |
| `vaultId` | string | Yes | Vault OCID. Key discovery additionally requires read access to this vault. |
| `keyId` | string | Yes | Encryption key OCID. Creating a secret requires a compatible enabled AES key. |
| `description` | string | No | Secret description. Avoid confidential information in metadata fields. |
| `secretContent` | json | No | Content object with contentType:"BASE64", optional base64 content, name and stage \(CURRENT or PENDING\). Maximum 25600 base64 characters. Creation requires content or automatic generation and allows only CURRENT. An update may omit content to generate a version using the stored generation configuration. |
| `secretRules` | json | No | At most one SECRET_EXPIRY_RULE and one SECRET_REUSE_RULE. Expiry fields: secretVersionExpiryInterval \(P1D to P90D\), timeOfAbsoluteExpiry \(RFC 3339, 1 to 365 days\), isSecretContentRetrievalBlockedOnExpiry. Reuse field: isEnforcedOnDeletedSecretVersions. |
| `freeformTags` | json | No | Free-form string key/value tags. Send \{\} to clear them. |
| `definedTags` | json | No | Defined tags by namespace, for example \{"Operations":\{"CostCenter":"42"\}\}. Send \{\} to clear them. |
| `metadata` | json | No | Additional metadata as JSON key/value pairs. |
| `enableAutoGeneration` | boolean | No | Generate new content with secretGenerationContext instead of supplying secretContent. |
| `secretGenerationContext` | json | No | Generation object with generationType, generationTemplate and optional secretTemplate. PASSPHRASE templates: SECRETS_DEFAULT_PASSWORD or DBAAS_DEFAULT_PASSWORD, optional passphraseLength. SSH_KEY: RSA_2048, RSA_3072 or RSA_4096. BYTES: BYTES_512 or BYTES_1024. |
| `rotationConfig` | json | No | Rotation configuration: \{targetSystemDetails:\{targetSystemType:"ADB",adbId:"&lt;ocid&gt;"\} or \{targetSystemType:"FUNCTION",functionId:"&lt;ocid&gt;"\},isScheduledRotationEnabled?,rotationInterval?:"P30D"\}. Scheduled intervals: P1D to P360D. The target and its IAM permissions must already exist. |
| `replicationConfig` | json | No | Cross-region replication: \{replicationTargets:\[\{targetKeyId,targetRegion,targetVaultId\}\],isWriteForwardEnabled?\}. Configure the source secret; Oracle enforces target limits and replica write restrictions. |
| `retryToken` | string | No | Optional idempotency token, 1 to 64 characters. Oracle tokens expire after 24 hours and can be invalidated by conflicting operations. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `status` | number | Oracle HTTP response status; 202 means accepted, not completed |
| `opcRequestId` | string | Oracle request ID |
| `etag` | string | ETag for optimistic concurrency control |
| `secret` | json | Secret metadata, rules and configuration |
